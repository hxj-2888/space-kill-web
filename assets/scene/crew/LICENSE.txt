# assets/scene/crew · 15 席角色行走图（Blender 重渲版）

## 许可：**本仓自绘，随仓库 LICENSE**

```
渲染：blender -b -P tools/blender-crew.py -- [--test] [--seats 1,2]
拼图：python tools/crew-sheets.py [--test] [--seats 1,2]
产物：crew-01.png … crew-15.png（15 套）+ manifest.json
中间帧：tools/_crew_raw/sNN_<dir>_<frame>.png（192×320，透明背景）
```

角色不再使用第三方行走图。早期 U1/R3 批曾用 *Cozy Space Station: Walking Crew*
（Bramble & Byte，CC-BY 4.0），UI-2 批起已完全替换；**不再附带 CC-BY 署名义务**。
旧程序生成像素图备份在 `_pixel-backup/`，仅作回滚，不再被游戏引用。

## 渲染流程（2026-10-28 重做）

- Blender 5.2 LTS，Cycles CPU，32 采样 + OIDN 降噪，透明背景，AgX 中高对比，曝光 0.75。
- 正交相机俯视 12°（2.5D 视角），正交尺度 2.62，画面 192×320。
- 三点布光：暖主光 + 冷补光 + 青色轮廓光；金属/织物/皮肤分别用 Principled 材质，
  织物叠加 Noise→Bump 织纹。
- 每个席位渲 4 方向 × 4 帧行走 + 4 帧待机 = 20 帧；PIL 用 LANCZOS 缩到 96×160，
  按 4×5 拼成 384×800。
- 拼图阶段做一次轻微调色（亮度 0.90、饱和 0.88、对比 1.05、冷色偏移），
  让角色贴近深蓝船舱底色；游戏内另绘脚下软阴影。

## 版式（**不要再改**，渲染器与帧动画依赖它）

| 项 | 值 |
|---|---|
| 单帧 | 96 × 160 |
| 网格 | 4 列 × 5 行 |
| 行序 | 0 下走 / 1 上走 / 2 待机 / 3 左走 / 4 右走 |
| 待机取帧 | 待机行第 2 列 |
| 行走动画 | 按时间切 4 列（`js/game.js` 的 `fr=Math.floor(T*7)%4`） |

## 差异化设计（15 席互不相同，且**与身份无关**）

- **配色**：15 色，与 `manifest.json` 的 `color` 同序（只做视觉辨识）
- **头饰**（15 种，一对一）：bare / antenna / cap / headset / crest / helmet / bun /
  spike / halo / visor-strip / horn / topknot / sidegear / wing / dome
- **背包**（5 种循环）：flat / tall / round / twin / none（只在背面与侧面可见）
- 体型/发型/肤色/护甲分块在脚本里按席位做微差，避免 15 人共用一张脸。

> ⚠ **外观不得与本局身份挂钩**。若让异形变红、外星人变紫，等于把阵营直接印在角色上，
> 违反防透视原则。这里只按**席位号**取样式，与 `role` / `faction` 无关。

## 修改约束

1. 不要改 `192×320` 渲染分辨率与 `96×160` 单帧尺寸：游戏按 `384×800` 切图，
   帧宽高比变化会让脚底对不齐格子。
2. 角色脚底必须落在帧底部约 2px 处（脚本相机 `CAM_CZ` 已标定），
   否则游戏里会出现悬空或陷进地板。
3. 头饰/背包的差异只按 `seat` 选择，禁止读取 `alien` / 阵营。
4. 重新渲染后必须跑一遍 `python tools/crew-sheets.py`，再跑
   `node tools/test-v3.cjs`（角色尺寸与不变量会被回归测试覆盖）。
