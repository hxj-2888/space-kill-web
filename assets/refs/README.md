# assets/refs · 设计参考图（**不发布**）

本目录只放**设计参考**，不放产品素材。三条规矩：

1. **不进站点白名单**（`tools/site-entries.cjs` / `tools/deploy-pages.cjs` 都不列它），
   所以这些图不会被部署到线上，也不会进 APK。
2. **不做产品引用**：`js/` 与 `css/` 里**不许**出现 `assets/refs/` 的路径（门禁 `npm run test:assets` 守）。
3. 每张图都要在本文件登记：文件名 / 出处 / 用途 / 是否可再分发。

## 为什么参考图要单独建目录（而不是塞进 assets/scene/）

`assets/scene/` 是**产品素材**：它有 `CREDITS.md` 许可证台账、有 `test-assets` 的"被引用"核对，
还要求"零引用素材"可追溯。设计参考图既不进构建、也没有许可证可依（它是别人的游戏截图），
混进去会让台账失去意义 —— 也就是"素材许可"和"设计参考"这两件事的边界被抹掉。

批 ART-0（2026-10-28）把这条边界显式化：

```
assets/
├── scene/          # 产品素材（必须登记许可、必须被引用或显式归档）
└── refs/           # 设计参考（不发布、不被引用、登记出处即可）
```
