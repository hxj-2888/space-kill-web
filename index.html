黑话术语表 · AI 发言识别全览

以下黑话 AI 全部听得懂——解析结果以小字「原意」显示在每条发言下方，并只增不减地写入各 AI 的证据台账，驱动怀疑度 / 投票 / 追责。语言库分两侧：理解侧（nlp.js：你说的话 → 意图）与生成侧（corpus/tactics.js + lang/renderer.js：AI 的话术库），下表是理解侧的完整对照。

① 查验汇报

金水 / 银水 → 引擎记「锁定·好人」汇报 + 辩护效应
查杀 / 实锤验出 → 「查杀（敌方）」汇报 + 重度指控
排除 / 已排除 / 肯定不是 → 排除汇报（反向通道证据）
锁定 / 验过 / 扫了 / 查验结果 → 锁定汇报

② 身份声称

我是神探 / 跳预言家 / 底牌是医生 → 身份声称（触发 R38 隐式自证；假身份被揭示吃 R30 硬置位 95）
悍跳 / 对跳 / 抢身份 → 标记冒充 / 两人同抢一职 → R12 对跳追责（+30，公开事实不衰减）
异形说「我查了 X」 → 来源致命 A⁻ +33：异形根本没有查验能力

③ 指控（三档）

重度：查杀 · 说谎 · 骗子 · 内鬼 · 聊爆 · 假冒 · 咬死 · 实锤 · 是异形 → 直接咬死档
中度：怀疑 · sus · 有嫌疑 · 像狼 · 盘出来 · 节奏点 · 重点关照
轻度：可疑 · 不对劲 · 踩 · 盯 · 挂一下 · 很怪
带「如果 / 万一」 → 假设降权（置信度 ×0.5~0.6，不算实指控）

④ 投票意向

归票 / 统一投 / 票别散 → 归票号召（AI 跟随主流票向）
分票 / 票散了 → 警告分票信号
压手 / 弃票 / skip / 不投 → 弃票（正常权利，信息门槛驱动）
出他 / 抬走 / 放逐 / 投 X 号 → 投票意向（宣称投 X 而 X 零票 → 抓谎 +25）

⑤ 辩护与背书

挺 / 保 / 信 + 编号 → 辩护背书（被挺者减疑）
站边 / 作证 / 金水位 / 清白 → 辩护；「抗推」者出局揭示后追责链反转（R17b）
自证 / 表水 → 空口「我是好人」−5；有证明链（声称职业+对账）−25

⑥ 承诺（强 / 中 / 弱）

强：「今晚查 X，明晚公告 X」——不兑现重罚
中：「我今晚要投 / 保 / 查 X」
弱：「可能会查 / 看情况」
兑现 → 给可信度 C 加分（+0.05/0.15/0.30）；保镖「我保护 X」公开不可验证、不吃未兑现惩罚

⑦ 证伪型否认（A12~A15）

我没被查验过 → 否认被查验（与查验者宣称为真冲突时暴露）
没被治疗 / 没有抗体 / 没进过濒死 → 否认被治/被救
没有感染标记 → 否认带标记（真实状态由系统对账）

⑧ 体验宣称（D 档）

用了感染抑制 / 我修了 / 在制药 → 私有体验宣称（不可验证，价值最低）
我治疗了 / 我救了 / 我带感染标记 → 部分可对账（⑫ 医生出手数公开）

⑨ 质询与划水

解释 / 交代 / 说清楚 / 昨晚在哪 / 摊牌 / 报身份 / 给我个说法 → 质询（被质询者吃压力，答不上来旁观 AI 记账）
划水 / 听大家的 / 没信息 → 划水（长期沉默触发 R34 扣分）

⑩ 职业别名（社区叫法 → 引擎职业）

船员：平民 · 白板 · 普通人　警长：船长
工程师：维修工 · 修船的 · 技工 · 扳手　助理：副工程师
生化医师：生化 · 医生 · 大夫 · 奶妈 · 奶　救援：救援兵 · 救援医
神探：侦探 · 预言家 · 警察 · 查杀位 · 验人位
保镖：守卫 · 护卫 · 盾位　验票官：票务 · 查票官
武装船员：枪位 · 猎人 · 带枪的　临时医生：代医 · 临时奶

⑪ 数字写法

阿拉伯数字、中文数字（一~十五）、「号 / 号位 / 号玩家」后缀均可——「十二号位」「5号自称验票官」「医生12号」「五号」 等写法全部解析
转述：「3号说5号是异形」→ 归因给 3 号而非自己背指控

⑫ 生成侧（AI 的话术库）

安全话术 N336~N347：票型承诺 / 弃票声明 / 附和 / 引用公开信息 / 认错 / 情绪表达——异形的全部发言空间（N348：只能维持基线）
禁区 N397~N400：异形说「X 是人类」、精确报行动数字、外星人明说蛰伏、神探公告密集期冒领——生成前直接拦截
