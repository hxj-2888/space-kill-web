夜间步骤：变形/觉醒（前置）→ 清洗（前置）→ 私聊 → 蛰伏（外星人，可附沉默）→ 窃听 → 感染抑制 → 感染致死 → 进化/转化/转职 → 乔装 → 查验/巡逻 → 保护/护甲 → 嗅探 → 维修 → 破坏/结茧 → 外星人击杀 → 开枪 → 异形行动（出刀/感染）→ 医生/毒师 → 死亡结算 → 紧急会议 → 倒计时。
伤害：造成濒死；抵挡层序「全额减免（安全室/夜晚免疫）→ 保护 → 巡逻 → 护甲 → 护盾」，每层挡 1 点；濒死的生路有三项——步骤 8 救援额度、外星人夜晚免疫（6.4）、死囚复生（6.8.4），先到先得；步骤 8 未获救则步骤 9 死亡硬结算，不跨夜。
感染：普通第 3 夜致死、感染进化第 2 夜；抑制延后 1 夜（终身 2 次，用掉当夜失去全部主动技能）；医生清除（真伪不可辨）；感染致死同样适用三项生路。
乔装：异形与外星人可乔装（每只全局 2 次）：普通型耗 1 次、只骗船员查验；强力型耗 2 次、兼骗蛰伏与神探查验（每个体至多 1 次），唯一反制是神探重复查验。
染血指认：同一凶手累计 3 次出刀致濒死后，其后的每一次出刀，被攻击者都会得知他的编号（不公开计数）。
停摆：破坏量自选档（未进化 1.5~2.0 / 破坏进化与外星人 2.0~3.0），⑤只公布当夜总量；净破坏 3.0 / 6.0 使倒计时 +2.5 / +5.0，9.0 人类倒计时胜利永久失效；维修效力被破坏进化按比例削减（次夜 25%/50%）。第 99 夜未决出即全局判平。
白天：（窃听报告 → 逃亡窗口 → 留言 → 摆渡人调查 →）自由讨论 → 投票 → 票数公开 → 驱逐（最高票、无平票、≥3 票）。
胜利：人类撑到倒计时归零或清场；异形人类全灭且外星人已灭；外星人残局独存或决斗僵局；99 夜未决判平。外星人另有次胜：积分达 10 分后可主动逃亡脱离对局，判次胜且对局继续（不得使人类或异形立即获胜）。
