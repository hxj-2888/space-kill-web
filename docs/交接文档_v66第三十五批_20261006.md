## 一、注意力挡位化（`moe.absorb`）

### 1.1 弱事件概率进账（floor 闸门软化）
批次 34 的硬闸「w < floor ⇒ 丢弃」改为：**按 θ 档 `attCatch` 掷一次，中则漏进**（0.30 / 0.15 / 0.08）。
- 拟真依据：人走神时也会瞥见不关心的事；激进广而浅、保守窄而深。
- rng 只在被闸的事件上消耗一次，未触发闸门零消耗，序列可复算。
- **挡位可关**：attCatch 覆写 0 ⇒ 逐字复现批次 34 硬闸（门禁 §28.1① 断言）。
- 纪律边界不变：未归族事件（w=1）不进此分支；私有源不经 absorb（红线 3）；硬源走 project 短路。

### 1.2 注意力容量（缓存，按目标数计）
`attCap`（12 / 10 / 8）按「当夜正在关注的目标数」计：
- **新目标占名额**，装满后新目标的事件截流；**已关注目标的后续事件不占新名额**——新面孔贵、熟面孔免费；
- 初版按「事件条数」计，实测截流 76%（一天的后半场发言整段消失）——既不拟真也不可用，改为按目标数后降到 9.9%；
- 开局日新面孔 14 人 ⇒ 三档都触顶（拟真：记不全 14 个陌生人的自称）；日常新目标 ≈2~5 ⇒ 多数日不触顶；
- 夜推进清零＝缓存换页；证据表一旦入账即持久，不做旧条淘汰（淘汰语义归内存）。

### 1.3 实测水位（30 局聚合，种子 1-30）
```
公开事件总 2585 条：入账 1890（73.1%）· 容量截流 257（9.9%）
· floor 丢弃 362（14.0%）· 漏进 76（2.9%）
```

| 容器 | 驱逐序 |

**实测**：有记忆者人均 13.8 条（四容器合计）。

## 三、定制发言（`js/corpus/voice.js`，新建）

- **三档声线**：激进（「我把话挑明——」「爱信不信。」）／中性（「我的看法是，」「先看着。」）／保守（「容我多嘴一句，」「姑且存疑。」）；私聊交底开场白同步分化（「跟你交个底：」／「私下跟你说：」／「小声跟你说一句：」）。
- **出现率** `voiceRate`（0.50 / 0.35 / 0.30）声明在 traits；开场 roll → 口头禅 roll（40%）顺序确定。
- **纪律**：只包装不改内容（正文逐字保留，§28.3 断言）；模板只引自身态度、无事实数字与职业/阵营词（天然过 Taboo，与 T18 同口径）；`voiceRate=0` 逐字回退（可整体关闭）。
- **私聊（quiet）**只替换交底固定前缀「私下跟你说：」；**队内频道（异形 squad）不在本层包装**——队内伪装语料有独立纪律，故意保留。
- 接线点唯一：`decide.speak` 出口（`engine.js` 与 `steps.js` 的公开/私聊消费都在其后），Bridge 与 noBridge 两模式同享；load-order +1（`corpus/voice`，noBridge/minimal 剖面不加载 ⇒ 缺席安全回退）。
