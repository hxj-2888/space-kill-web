## 〇、三句话

1. **叙事层＝系统叙事**：终局复盘编年史（本方案主体）＋公告正典呈现（已 IR 化）；**AI 拟人化不属本层**（v4.0 批次 22，门控非异形 AUC≥0.55，出界）。
2. **局中系统旁白不做**——7.1 最小信息下它无合法信息增量：含公告外信息即违规（2.8.7），不超公告即冗余。叙事层的局中存在感就是公告正典文本本身。
3. 全部施工**零写对局状态**：narrator 是终局后的读侧纯函数，指纹与对局行为零接触；UI 挂载做「并排页签」不替换原始数据，可回退。

## 二、规则地基：信息披露的两域三检

| 检查 | 局中（公告、引导文案） | 终局复盘（2.6.3 全知解锁） |
|---|---|---|
| A report（4.10.6 不带次数） | **适用**——系统叙事不得含份数措辞 | **放宽**——全知制度下份数可叙述；但引擎本就不存逐次记录（deathCauses 采集即去重），叙述以类别为主干 |
| B expose（2.8.12④） | **适用** | **放宽**——终局揭示全阵营 |
| C checkClaim（4.7.1/4.7.5②） | **适用** | **仍适用**——这是事实准确性约束而非披露约束：变形可骗神探，「查验结论一定没错」在复盘里同样是假话 |

推论：Taboo 三检中 A/B 是**披露类**（随 2.6.3 制度放宽），C 是**准确性类**（恒适用）。narrator 的出口校验恒跑 C；A/B 仅在其文本用于局中时跑。此口径已写入方案 §五门禁，实施时回填 taboo.js 头注一句话。

## 三、架构

```
g.replay / g.log / g.players / g.tiers / g.winner      （事实源，只读）
        │
        ▼
Narrator.chronicle(g) ──纯函数，仅 g.over 后有定义──▶  NarrativeDoc
        │                                              { meta, chapters[], verdict }
        ▼
Narrator.renderDoc(doc) ──确定性渲染──▶ 文本（工具面 / 未来 UI 页签 / 语音位）
        │
        └─ 出口校验：Taboo.checkClaim（恒）＋ A/B（仅局中文本）
```

**不建第三套 IR（决策）**：复盘是终局一次性生成、单一全知视角、无交互；IR 的价值在多视角/多消费面，此处暂不存在。NarrativeDoc 与 IR 同构（结构化数据＋确定性渲染），将来要语音/回放分享时升级成本是一个函数。**两处复用必须做到**：死亡章节直接嵌入 AIR death 节点渲染结果（4.10.6 正典格式是事实锚，不得重述第二套口径）；终局判定行复用 1.2.3 顺序号。

**NarrativeDoc 章节模型**：

```
meta:     { seed?, winnerName, nightCount, mode }        // 批次〇配置重述
chapters: [ { night, phase: '常规'|'寂灭'|'决斗',
              blocks: [ opening | deaths(⑥+AIR) | vote(⑨⑩) | evolve(②)
                      | economy(④⑤+停摆) | phaseSwitch | duelStalemate
                      | countdown(⑧+档位) | omniscient(god 流水折叠段) ] } ]
verdict:  { order: '①|②|③|④|平局', text }               // 依 1.2.3 判定顺序叙述
```

分层叙述：**披露层主干**（公告重述，玩家复盘该看的口径）＋**全知细节层**（god 流水，折叠段）。即使 2.6.3 全知解锁，两层分列保持可读性，也为将来「出局者局内限览」预留裁剪位。

## 五、纪律（与治理规范对表）

1. **指纹纪律**：narrator 零写状态；§22 纯函数断言把「写状态」钉死为回归项。
2. **B3/K3**：叙事仅经 `View.replayOf` 制度可达（N2 页签读同一份 end.replay 派生数据）；进行中调用恒 null。
3. **推理隔离**：narrator 输出不进任何 AI 消费面——e10 等判据读 `g.log` 的 batch 字段，NarrativeDoc 不落盘，天然隔离；任何把叙事文本喂给 AI 的提案都属新透视通道，须单独评审。
4. **防指标博弈**：叙事层不进任何指标与 gate；人审样本种子隔离（1-30 调试，101+ 抽验）。
5. **正典不可变**：AIR 渲染串逐字节复用，narrator 不得重拼揭示字段（§22⑤ 断言）。
