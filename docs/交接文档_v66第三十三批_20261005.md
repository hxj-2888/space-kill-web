## 〇、三句话

1. **AI 现在有三种「像人」的能力**：跨夜**记得**（长期记忆）、指控时**给出理由**（推理链发言）、复盘时**讲自己的故事**（叙事）。三项各有独立模块与门禁。
2. **纪律优先于拟人**：记忆只记合法持有的公开信息（否则记忆即透视）；推理链取不到依据时返回 null 回落旧模板（**不强凑**）；叙事经 Taboo 出口校验。三条都写进了 §26 断言。
3. **指纹是有意变更**：发言文本改变 → rng 序列变化；且更具体的发言带来了可观察的行为变化（夜均 7.4→7.0、驱逐 6.23→6.17）。

## 一、拟人层 A · 长期记忆（`js/ai/memory.js`，新建）

### 1.1 设计要点
与既有设施**三分**，避免三处并行维护同一件事：

| 设施 | 存什么 | 用途 |
|---|---|---|
| `tEvents` | 单夜证据事件流 | 推理输入（**不归并**） |
| `claims` | 发言原文流水 | 复现与 NLP 解析 |
| **AIMemory** | 跨夜**归并后的印象** | 发言时能引用的那一句「因为」 |

四类印象，对应人脑的四类：**自称**（谁说过自己是什么）、**承诺**（谁答应过什么）、**矛盾**（谁的话被证伪——人脑反应最强的一类）、**立场**（他一直站谁那边）。

### 1.2 记账入口（三处，均为「人人都听见了」的公开信息）
- `perceive.onClaim` —— 每位观察者记「谁自称什么」；**自称改口即矛盾**；
- `pipeline` 承诺入账 —— 每位观察者记「谁答应过什么」；
- `perceive.onVoteSettle` —— 由 `g.voteSources`（公开票源）归并立场。

### 1.3 纪律
- **只记合法持有的信息**：不记任何隐藏字段（他人真实身份/阵营/私有额度）——否则记忆即透视，违 7.0。§26.1 以「记忆条目不含 truthRole/truthFaction」断言把守。
- **按夜去重**：同一夜同一人的两次自称记一次（人不会把同一夜的两次自称当成两件事）。

## 二、拟人层 B · 推理链发言（`decide.reasoningChain`，新建）

人指控时几乎总会给理由，而理由来自**自己记得的**具体事。`reasoningChain(g, p, target)` 按优先级取一条最强的「因为」：

| 优先级 | 来源 | 例句 |
|---|---|---|
| ① | 硬源（自己查过／神探池／官方揭示） | 「我查过 3 号，他是工程师。所以我投他。」 |
| ② | 长期记忆（改口 > 自称 > 承诺 > 立场） | 「他第 2 夜说自己是警长，第 4 夜又说自己猎人。一个人两张脸，我不信他。」 |
| ③ | 证据链（只报条数，不泄露内容） | 「我对 3 号的怀疑不是一天两天了，攒了 5 条对不上的地方。」 |

**取不到依据时返回 null**，调用方回落到旧的无理由模板——**不强凑**，避免生成无依据的话（这是与「AI 胡说」的关键区别）。

实测（seed 3，84 对存活目标）：自称 6、立场 23、证据条数 16、null 11 —— 四档均触发。

### 实现中的一个真 bug（已被门禁抓到）
首版 `const t = target` 直接把**玩家对象**当 Map 键查，全数 miss，链条产出恒为 0。修正为取 `.id`。教训：记忆类容器的键类型必须与写入端一致，写入端用 `p.id`（number）时，读取端不能直接收对象。

## 三、拟人层 C · 叙事（`narrator.voice`）

同一份编年史，人讲和 AI 讲的差别不在**事实**，而在**取景**：人会挑自己参与过的片段、带上自己的判断与情绪。`voice(doc, {me, mem, aliveIds})` 只做取景与口吻，**不新增任何事实**（所有数字与事件都取自 doc），且：

- 只取该说话者**亲历**的片段（`pickShots` 的持有性检查）；
- 出口恒过 `Taboo.assert(text, 'checkClaim')`（查验结论不得断言为硬事实）。

样例（seed 5，5 号视角）：
```
我盯得最紧的是 3 号。
第 1 夜，3 号死亡，人类（呈现职业：警长／真实职业：警长），尸体调查报告：【异形出刀】——那晚之后节奏就变了。
结局：② 外星人清场：非人类仅剩人类。5 号救援医师、12 号武装船员。
我活到了最后，但我也不敢说赢得漂亮。
```

## 五、§26 门禁（10 条，防能力退化）

| 组 | 断言 | 守住什么 |
|---|---|---|
| A | 记忆被记账 / 自称与立场形成 / 按夜去重 / **不含隐藏字段** | 记忆不是透视 |
| B | 链条可生成且**不强凑**（成链 > 0 且 null > 0）/ 指控带因 > 0 / **不直接断言他人真实阵营** | 不胡说不泄露 |
| C | 叙事可生成且含个人立场 / 过 Taboo checkClaim / **纯读** | 叙事不撒谎不改局 |
