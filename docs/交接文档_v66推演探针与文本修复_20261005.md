## 一、新增：`tools/trace-game.cjs`

| 项 | 内容 |
|---|---|
| 用途 | 把一整局跑完并打印**推理链每一步**：夜间决策（选了什么）→ 公告批次 → 公开发言（含 Claim 意图）→ 推理读数（怀疑度/危险度/信念分布/硬源标注）→ 证据表 → 票型与「投票—推理一致性」→ 结局与结算读数 |
| 用法 | `node tools/trace-game.cjs [种子] [--verbose] [--quiet] [--hunter] [--listener] [--poisoner]` |
| 与 mc/sim 分工 | mc＝**批量统计**（AUC/盲区/败法分布）；本工具＝**单局可读性**（「这一局 AI 到底在想什么、想对了没有」） |
| 治理 | 只读探针；读数不进 gate；种子 1-100 为调试区间（本工具默认种子 7），101-500 为验证区间 |

**实现要点（三条自踩自纠，写下来备查）**：
- **驱动方式**：日志游标（`logCursor`/`chatCursor`）＋ 阶段检测，而非「比对上一步」——后者会在同一 `stepDone` 上反复命中，把同一条公告打印多次（首版即如此）。
- **投票—推理一致性**：取**投票发生前**的怀疑度快照。投票后再读会把「投票结果本身」算进推理依据，恒得高一致（循环论证）——首版读到 0/14 的假信号即此故，修正后为投票前快照。
- **AUC 采样**：与 mc.cjs 同式——人类观察者 pos＝异形+外星人／异形观察者 pos＝人类、neg＝外星人（非队友）／外星人观察者 pos＝异形。首版误把异形/外星人排除在采样外，读数不可比，已纠正。
