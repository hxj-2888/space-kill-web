## 二、决策

1. **不创建** `gitee.com/hxj-2888/space-kill-web` 仓库，也不把网页版代码推到 `space-kill`。
2. 太空杀网页版仓库**只保留 GitHub 远程**（已 `git remote remove gitee`，不留坏配置）。
3. 附件站（`space-kill`）本次更新只推 GitHub，由其 CI 自动部署到 `space-kill.pages.dev`。**Gitee 上那份是过期的**（仍是公测 3.0 口径），需要同步时手动补一次推送即可。
4. 作品集保持双远程（gitee 上是有效的）。

## 三、以后要恢复 Gitee 同步时的操作

```powershell
# 1) 在 Gitee 网页端新建空仓库 space-kill-web（不要勾选 README/.gitignore）
# 2) 本地登记并推送
cd <本地>/太空杀游戏-完整版
```
