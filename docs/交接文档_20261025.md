### 本轮踩坑实录（每条都付过时间，接手必读）

1. **★ `V.humanId`（S3b-2 修，S1 起潜伏）**：`View.viewFor(g,pid)` 顶层是 `{view, humanId, omniscient, players,…}`——**「我的 id」是 `V.humanId`，没有 `V.id`**。SKScene 8 处 `V.id` 恒 undefined ⇒ 自己金环/夜间自己睁眼例外/跨局签名三个表现自 S1 起失效（多闭眼=保守方向，**无泄露**）。教训：**对接 view.js 先量返回形状**（vKeys 一眼可查）。
2. **本地 MIME 缺表**：`server.js` 只认 html/js/css/md，`.svg` 以 octet-stream 下发 ⇒ `<image>` 安全策略拒渲染（席位全成 Chrome 破图占位「白绿山形」）。补 `.svg/.jpg/.png/.webp`。CF Pages 线上默认正确，仅本地缺。
3. **CSS 特异性**：03 层 `#screen-game .seg-roster .roster`（1-2-1）压掉 06 层 `#screen-game .roster`（1-1-0）——场景接管静默失败。规则：**跨层覆盖一律对齐特异性并靠加载序**。
4. **等弧长表 NaN**：`target=0` 时二分读 `acc[-1]`=undefined → f=NaN → 坐标 NaN。**S0 预览曾被 CSS 初始位掩盖、S1 的 SVG 直接暴露**——「预览正常」不等于「无 NaN」。
5. **`g.nightChats` 时机**：0c **结算时**落库（窗口内为空）；0c 私聊输入走 **form 的 text 槽**（`#f-form-text`→run 交付），不经 Engine.talk/chatLog ⇒ 「发言」页签无泄露。实时私聊气泡的数据源必须与日记本统一（见 §五待办）。
6. **05 层矮横屏预算**：`#screen-game .board` 单列 + `grid-template-rows: 46px 1fr`（旧 roster 横条）——场景化后必须**逐项压回**（rows 显式覆盖），否则主区被压进 46px 行。
7. **mobile-check 相位扫描**已重写为场景主区断言（6 相位 × applyStageLayout 幂等回归：场景可见/主区吃满/面板限高/场景 ≥100px——SE 最矮档实测 119px）。
