### 3.1 目录与分层

```

css/08-home.css     主页重构（登船名册 + 登船通道 + 结算页名册）★ 必须排在级联最末

tools/gen-room-scenes.cjs  房间场景生成器（改一间只改一处配置）

```

### 3.2 ★ 级联顺序：新分片必须排在 08 之后

`css/style.css` 的 `@import` 顺序 = 级联顺序。新增分片要压过前面各层，
就必须排在后面，且**断言要守「相对顺序」而不是「谁是末位」**——
R5 加 `08-home.css` 时，`S4F` 断言因为写死了「07 必须是最后一个」而变红（已改为「07 晚于 06」）。

### 3.3 ★ 特异性打架：三处典型

1. **`.opts` 有三层规则**：01 层 `display:flex; flex-direction:column`、`.opts.grid3` 是 grid、
   06 层又覆盖一次。做头像目标选择时只 `!important` 了 `display`，头像仍是**单列**占满整屏。
   必须同时压 `display / flex-direction / flex-wrap / grid-template-columns` 四项。
2. **`.sk-room-art img` 命中缩略图**：该规则是 64×64 绝对定位，房间缩略图被钉成 64px
   只露出一角（看起来像「左半边空白」）。需 `.sk-room-art img.sk-room-thumb` 更高特异性。
3. **`.start-box > *` 压掉装饰件定位**：同特异性靠后取胜，会静默把 `position:absolute` 压成 `relative`。
   修法用 `:not(.start-scene)` 显式排除，不靠顺序。

### 3.4 ★ 高度预算会被上层吃掉（矮屏必查）

05 层 `#screen-start .panel-grid{max-height:none;flex:0 0 auto}` 会把剩余高度全给对局区，
新加的名册作为 flex 子项被 `flex-shrink` 压成 **3px 细线**。
修法：显式 `flex:0 0 auto; min-height:44px`。同类坑 S5 已踩过一次（roster 横条 46px 预算）。

### 3.5 ★ 断言纪律（本仓血的教训）

- **不许恒真式**：本轮我自己先写过 `X === false || true`，等于删掉断言还假装它在守。
- **断言不许读错文件**：`主区M` 首版在 `ui.js` 里找房间声明，而声明在 `ui-scene.js`。
- **正则要容忍多行**：CSS 是多行书写的，`\{ max-height` 匹配不到 `{\n    max-height`。
- **每条新断言都要做反向自检**：改坏实现必须变红，且**只触发自己那条**。
  本轮 R3/R4 做了 6 条变异逐一验证（见 `改动说明.md` 批 R4 §三）。
- **反向自检的基线用 golden 快照，不要用 `git show HEAD`**——改动未提交时「还原」会把改动一起抹掉。
