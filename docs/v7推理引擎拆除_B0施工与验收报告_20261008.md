### 一处夹具脆弱性修复（`拟人B`）

## 五、顺带修掉的一个真实缺陷（非本批引入）

**外星人 `P-id` 声明缺口。** 引擎步位 `'P-id'`（身份改变子步骤，2.1.1）的 `req` 会向
经典外星人派发 `awaken`（6.2 觉醒：第 6 夜起或存活≤6），但 `roleDecl` 原只登记
`['0.1','0.1s','4b','5']`，缺 `'P-id'` ⇒ `coverageGap('P-id',['xeno']) = ['xeno']`。

- **该缺口在拆除前的基线同样存在**：基线 `declaredActors('P-id')` 亦只有 `['convict']`。
  只是当时采样未命中；B0 后 rng 序列前移才被 C1 审计扫到。**故属既有缺陷被暴露，
  不是 B0 引入的回归。**
- **无行为风险**：`roleDecl.js:42` 的契约写明 `actionSteps` 全列表「供覆盖审计与 C1 收口」，
  引擎派发过滤读的是主行动位 `actionStep`（本行仍为 `'0.1'`，未改）。
  死囚（上一段）已按同一口径登记 `'P-id'`，补齐后两角色对齐。

## 六、⚠ 必须如实报告的指标变化（铁律四/五）

**B0 不是行为中性改造。** 同种子（1–200）、同驱动口径，独立对照：

| 指标（每局） | 基线 | 拆除后 | Δ |
|---|---|---|---|
| 完成局数 / 异常 | 200 / 0 | 200 / 0 | — |
| **人类胜率** | **31.0%** | **72.5%** | **+41.5 pp** |
| 异形胜率 | 56.5% | 12.5% | −44.0 pp |
| 外星人胜率 | 12.5% | 15.0% | +2.5 pp |
| `decide` 调用 | 271.8 | 246.6 | −9.2% |
| 非空决策 | 25.3 | 21.6 | −14.8% |
| 异形击杀决策 | 9.9 | 6.9 | −30.3% |
| 人类被淘汰 | 9.9 | 6.9 | −3.1 |
| 异形被淘汰 | 2.1 | 2.7 | +0.7 |

**这不是「异形停摆」**：异形每局仍发起 6.93 次击杀决策（基线 9.94）。变的是**人类阵营
不再自己淘汰自己**（被淘汰 9.9 → 6.9/局）。

这一跃变与先前的分解结论一致：`ask` 通道单独 AUC 0.2705（**反向**）、占证据质量 29.5%，
撤掉它带来 +0.1317 AUC。人类角色的投票一直被这批噪声污染，拆除后投票质量反而回升。

**但 72.5% 的人类胜率很可能让游戏变得没有难度。这是一个设计判断，不是可以顺手"修"的指标：**
按铁律一，指标只作观察、不进门禁 —— 我不会为了把胜率调回 31% 去反向塞回证据噪声。
是否接受这个新的难度基准，需要你拍板。
