## 1. 本轮全部实测结论（方案的证据地基）

### 1.1 威胁度量：证据量与「是人类」正相关

| 目标阵营 | 人均证据条数 | 人均负向量 |
|---|---|---|
| 人类 | **2.05** | 13.09 |
| 异形 | 0.94 | 7.39 |

人类/异形 = **2.19× 条数**。异形低调不被追问，账本干净 ⇒「证据越多」实测是**清白信号**。

**通道级投毒溯源**（`channel-poison.cjs`，9685 观察者组）：

| 通道 | only(c) AUC | 证据量占比 | drop(c) 后 ΔAUC |
|---|---|---|---|
| **ask（质询）** | **0.2705** | **29.5%** | **+0.1317** |
| king（沉默指纹） | 0.5217 | 4.9% | −0.0207（唯一有效） |
| accuse（指控） | 0.4622 | 5.1% | +0.0044 |
| 全量基线 | 0.3378 | 100% | — |

被追问 = 显眼 = 大概率是人类。真人不会把「被追问次数」当罪证。

### 1.2 最优量化口径与种子隔离验证

| 口径 | AUC |
|---|---|
| A0 全量负向（现行底层） | 0.3378 |
| A1 剔除 ask+accuse | 0.4817 |
| **A7 剔除 ask+accuse ÷ 可见度** | **0.5586** |

**种子隔离**（铁律四，不重叠）：标定集 1–120 = 0.5601，验证集 121–240 = **0.5737**（Δ0.014，噪声内）→ 未过拟合。

### 1.3 信息的硬约束：可验证信息完美但覆盖 0.39%

硬源准确率 **100%**（12,829 条锁定零错锁），覆盖率 **0.62%**。

## 2. 决策：取消推理通道

### 2.1 依据

文档台账已记录三档独立沙箱消融（`tools/channel-ab.cjs`，200 局/验证集 501–700）：

| 档位 | 旧判据 AUC | top1 | gate 求值 |
|---|---|---|---|
| `full` | 0.500 | 61.8% | 496,144 |
| `late`（残局限定） | 0.498 | 64.0% | 97,328 |
| `off` | 0.498 | 63.8% | **0** |

**边际贡献 +0.002，开局与 top1 上是负贡献**；证据构成里 claim 占 97.4%、通道 universal 仅 0.7% ⇒ **通道库从来不是首要素材**。

本轮独立复核：`chan` 改道入账 489 次 / 241,816 次 `reason` 改道 = **0.2%**；偏ρ = +0.234。

**裁定：取消推理通道（`SK_CHAN_MODE` 三档机制整体废止）。**

## 3. 新架构：角色分层推理引擎

### 3.1 三段管线（替代通道）

```
① 私有观察采集  rolevision.js   —— 按角色声明「他能看见什么」采集结构化观察
② 推理素材生成  roleinference.js —— 观察 + 记忆 → 推理素材（带出处/时效/强度）
③ 消费          threat.js + decide.js + speak.js —— 素材驱动威胁度量、发言、行动
```

**核心不变式**：素材**只允许**由①的合法观察与 `AIMemory` 派生，**永不读取真相字段**。`decide.js`/`speak.js` 不得直接读 `x.faction`/`x.role`（除自身）。

### 3.2 各角色「应当有哪些推理」（从规则正文反推）

逐条对应 `roleDecl.js` 已声明但 AI 未消费的 `visibility` / `attend` / `grants`：

| 角色 | 规则依据 | 应当具备的推理 | 现状 |
|---|---|---|---|
| **神探** detective | 4.7.1/4.7.3/4.7.5 | ①查验结果→定基调 ②**公告转化率最大化**（每夜把一条 AUC=1.0 信息 ×11 人）③预告可信度维护 | 查验 2.17/局、公告 0.49/局，偏ρ=**+0.056** |
| **验票官** inspector | 4.9.1/4.9.7 | ①票型→责任链（R27/R28/R40）②弃票声明对账 ③**票源独占推理**（唯一票源持有者） | 投票命中率 31.4%（**全场最低**） |
| **警长** sheriff | 4.4.2/4.4.4/4.4.5 | ①威胁→射击选择 ②巡逻保护优先级（N415）③**夜袭者名单复盘**（`gunAttackers`）④悬赏 | 开枪 0.23/局 |
| **猎手** hunter | 4.4.7/4.4.8 | ①攒弹节奏 ②**嗅探结果推理**（`sniffLog`，是否呈现保护状态）③无巡逻 | **局数 0** |
| **工程师** engineer | 4.3.2/4.3.6 | ①维修量→暴露风险权衡 ②④暴露后的自保推理 ③**维修效率被抵消的归因** | 维修 0/局（读坏掉的 dangerOf） |
| **保镖** bodyguard | 4.4.9/4.11 | ①守卫目标选择 ②**「我守的人是否遇袭」的结果反馈**（`guardedBy`） | 信息通道 1 种 |
| **生化医师** bio | 4.5.1/4.5.2 | ①标记清单→真伪判别（R7 假标记回流）②治疗资源分配 ③抗体优先级（N416） | markSeen 常为 0 |
| **救援医师** rescue | 4.6.1 | ①濒死清单→救援价值 ②**尸体调查报告归因**（`deathCauses`） | dyingSeen 0 |
| **船员** crew | 4.1.1 | ①双查验证式推理（当前最活跃：6.76/局）②转职缺口判断 | 唯一有真实决策的角色 |
| **异形** alien | 5.8/2.2⑤ | ①清除威胁（读修正后 threat）②队友协同投票 ③**伪装一致性维护** | AUC 1.0（硬源恒等） |
| **外星人** xeno | 6.x | ①第三方最优 ②双刀 ③**免疫余额与沉默取舍** | AUC 1.0 |

**关键发现**：上表「现状」列中 8 个角色的核心推理**当前为零或近乎为零**，而规则正文已明文赋予他们这些能力。**声明层写了，引擎没接线。**

### 3.3 注意力与记忆的正确定位

上一轮已证：注意力若作用在「证据量」上，只会放大可见性偏置。正确用法：

| 机制 | 现状 | 新口径 |
|---|---|---|
| **注意力（写作侧）** | `ATTEND` 族权重 + floor 闸门，方向正确但幅度仅 1.0~1.3 | 改为**素材族权重**：每个角色只允许生成与其 `attend`/`attendAway` 相符的**素材**（不是加权证据，而是**限定素材种类**） |
| **注意力（门控）** | `attCap` 缓存截流（3766 次）、`attCatch` 漏进（493） | 保留，但**只对软素材生效**；硬素材（查验/票源/守卫结果）**豁免**（对齐 `absorbPrivate` 红线 3 的既有语义） |
| **记忆** | 立场强度偏ρ=**+0.544**（全场最强可控杠杆），但改口/矛盾 ρ≈0.008 | 保留并**提权**；矛盾与改口需修复 `checkRoleConflict` 的跨夜冲突判定（当前 135 次，疑似低报） |

### 3.4 威胁度量重建（A7 口径）

```
threat(o, x) = 可验证层 × 1000 + 软素材层 / (1 + visibility(x))
  可验证层：known 硬锁 / o.checkPool / o.crewChecks       （AUC 1.0，权重最高）
  软素材层：Σ 素材强度 × 衰减(0.85^夜) × 可信度C × 注意力
            排除 ask / accuse 两族（可见度代理）
            排除 tEvents 中 x 已出局后的条目（剪枝，对齐种子42「证据表含死者」）
  visibility(x) = x 被全体观察者记录的素材条数（跨观察者去偏，非单视角）
```

**不改动 `dangerOf` 的签名与量纲（0–100）**，26 处调用点零改动；只换内部实现。`actF` 与 `capability` 两个反向项（AUC 0.335 / 0.472）从威胁计算中移除，改由「可验证层」承担。

## 5. 断言设计（铁律三：不得反向断言）

每条新断言须注明依据来源，且判据自检：「**故意把实现改错，它会挂吗？**」

| 断言 | 依据 | 挂的判据 |
|---|---|---|
| 归档完整性 | 文档 §批次 25 台账 | 归档文件缺失/条数≠506 即挂 |

| 硬素材豁免注意力 | §3.3 红线 3 | 硬素材被 `attCap` 截流即挂 |

| 铁律 | 本轮落实 |

| 非异形 AUC 0.431 → 0.55+ | A7 已验证 0.5737 | 显著 |
| 神探信息覆盖 0.62% → 5%+ | 偏ρ +0.056 但信息 AUC=1.0 | **最高杠杆** |
| 角色投票离散度 31~42% → >15pp | 当前统计不可区分 | 拟人度核心 |
| 异形投己方 116 次 → 0 | decide 弃保跟票读修正后 threat | P0 |

### 失败模式（预登记）

| 风险 | 迹象 | 处置 |
|---|---|---|
| **A7 去偏过度** | 高怀疑目标被系统性压低，全场都不投人 | 检查 `visibility` 分母是否被 `known` 灌水 |
| **威胁层确定化 → 发言更模板** | 发言多样性从 25% 继续下降 | 素材须带**叙事性描述**而非仅分数（对接叙事层） |
| **B3 行为指纹剧变** | 全部旧断言失效 | 分两次 PR：先换 threat 实现保留 dangerOf 签名，后改 decide 读取 |
| **通道删除后云臂输入减少** | 文档已警告云与通道非互斥 | `absorbPrivate` 删除前先确认云臂不读 `uEvents` |

## 8. 待裁决项

1. **B3 是否单独 PR**（我建议是——它是唯一有真实性能风险且不可逆的改动）。
2. **叙事层是否在 B2 接入**（素材若只有分数，发言会更模板；接入叙事可缓解，但会扩大改动面）。
3. **5 个未出场角色的入席方式**（改组局表 11 席 → 更多席，还是转职池扩容）。
4. **`pickCitable` / `squadRoles` 两个零消费者函数**：随 B0 归档还是补消费者。
