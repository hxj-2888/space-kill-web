## 三、★ 本轮最值钱的三个发现（都是「此前没人发现」）

### 3.1 设置面板三个控件**全部点不动**，不只是规则速览

用户报的是「设置里的规则速览选项无效」。做了一次 `elementFromPoint` 逐控件命中检测：

```
#btn-music-start   命中自身              OK
#btn-sfx-start     命中 #arena-stage     X
#arena-tempo       命中 #arena-stage     X
#btn-rules-start   命中 #arena-stage     X
```

**根因**：`07` 层把 `.start-box` 的子元素统一压成 `z-index:1`，而 `.arena-stage` 是 `z-index:2`；
设置面板挂在 `.start-top` 里向下弹出，下半部分正好落在场景区上。
在面板自己身上设 `z-index:30` 无效 —— **z-index 只比同层叠上下文**，必须提 `.start-top` 本身。

> 如果当时只按字面「删掉规则速览那一行」，音效与音乐速度会**继续坏着**，而用户下次还会来报。

### 3.2 角色行走「完全是平移」，根因在素材不在 CSS

逐像素比对 15 套行走图，**每一行**都是：

```
帧0 vs 帧1  →  736 px 不同
帧0 vs 帧2  →    0 px 不同   ← 完全一样
帧0 vs 帧3  →  672 px 不同
```

腿部只横移 **1px**（`SWING=[0,1,0,-1]`）。1px 放大 4 倍 = 4 物理像素，而角色只有 64px 宽 —— 肉眼为零。

> CSS 动画本身是正常跑的（采样到 `transform` 确实在 `0 → -96 → -192 → -96` 循环）。
> **用户说「没有动画」是对的，但原因不在他认为的地方。**

### 3.3 对局回放形同虚设，因为从来没有存储层

```
arena.js  #btn-replay-home → View.replayOf(g)
View.replayOf(g) = (g && g.over) ? (g.replay||[]) : null   ← 进行中恒 null（K3 红线）
全仓 localStorage 只存了 sk_rules_seen 与玩家名
```

所以除了「刚打完且还停在结算页」之外，这个铭牌永远只弹一句提示。**这不是 bug，是缺一层。**

## 六、本轮 6 条教训（按可复用价值排序）

### 6.1 「结构信号」比「字面模式」可靠得多

PDF 解析器试了三轮才对（9 张 → 0 张 → 更糟 → 14 张全对）：

| 版本 | 我的假设 | 实际 |
|---|---|---|
| v1 | 标题 = 「名+阵营+·+N名」 | 还有「与…同席位」「同属步骤3行动位」等任意短句 |
| v2 | 用字号分标题 | 职业名是 **7.5pt**（与正文同字号） |
| v3 | 自己按 y 坐标聚类成行 | 3pt 分桶把标题与正文并在一起，截成「化医师」 |
| v4 ✅ | 用 PDF 自带 line + 「下一行是表头『项』」作闸门 | 14 张全对 |

> 卡面每张卡都是「标题 / 项 / 口径 / …」的形状，而正文里没有这种排列。
> **判据要落在「周围的结构」，不是「这行长什么样」。**

### 6.2 「压暗」和「压成黑」是两件事（第 3 次复发）

新内衬瓦片第一版平均亮度 **31**，而房间地板压暗后约 **143** —— 差 4.6 倍，开始页整屏读作纯黑。
提到「房间地板的 45%」（亮度 74）后成片。

> 批 UI-6 记过「边条压太黑 = 另一种黑区」，这是同一个教训的第 3 次。**调亮度前先量两个数。**

### 6.3 同名选择器 + 后加载 = 静默覆盖

只改 `07-start-scene.css` 的 `#screen-start::before` 背景，截图仍全黑 ——
因为 `09-arena.css` 里有**同名、同特异性、后加载**的规则把 `background` 整段替换掉了。

> T3b 就是守这个：**背景图必须由最后加载的那一片自己带上。**

### 6.4 「算出来了但没写出去」比「没算」更难查

`const delay = ((p.id * 37) % 220)` 算得好好的，`style` 里只写了 `--dx/--dy`。
而 CSS 变量**可继承** —— 重建 DOM 后新元素继承上一次的值，行为不可预测。

### 6.5 先算 key、再改状态 = 状态与 key 不同步

UI-8b 第一版只删了 `kind`，但 `phaseKey` 仍算在自动跳房之前。于是房间改了、`walkUntil` 还是旧值
⇒ **15 个角色瞬间跳到新座位，一帧动画都没有**，比原来更糟。

### 6.6 断言会被自己的说明文字判红

两次：T1b（HTML/JS 注释里提到被删的 id）、R3（产物注释里写「不含 V6.6 内容」）。

> **规则：凡「某字符串不得出现」的断言，必须先剥注释，或者干脆别在注释里提它。**
