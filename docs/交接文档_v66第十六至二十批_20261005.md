5. **诚实记录（铁律五）**：每批必须列「本批变坏的指标」；若全部指标改善视为可疑信号。17a 的探针读数记「17b 预期缺口」，不混「本批变坏」。

## 4. v4.0 施工序与当前判定

```
批次16 清障 ✅ → 17a 云原型 ✅（未接线）→ 17b 前置清零 ✅ →【改判：先调模型】→ 17b 接线（未放行）
   → 18 专家 run×13+Claim 可靠度 rel+命名空间统一 → 19 倒排接 AI+44 gate 清+R 降级+派发过渡
   → 20 叙事层+五变体 → 21 时序+仲裁+承诺 → 22 拟人化（仅当 AUC>0.5）
```

**「先调模型」的三个候选机制方向（逐项须机制论证，禁止 AUC 反推）**：
1. `PRIOR_REG=0.05` 每夜向先验回归稀释强信号——旧累加器残局优势来自「fact 不衰减+近期强证据主导」；
2. `W_CAP=0.35` 饱和位移把证据强度压缩为方向质量，多条同向证据的聚合表达不足（GAIN 通道弱）；
3. C 档（rel=0.4）位移幅度可能过小。

**判定门（17b 放行条件，D3）**：非异形观察者 AUC ≥ 0.55 且不低于旧侧（当前 **0.515** vs 旧 0.500——高于旧侧但未达标）。达标前不得动 `dangerOf` 接线。
