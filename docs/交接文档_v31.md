### 2.3 一次对局的通路


## 3. 红线（改代码前必读，违反其一即视为破坏架构）

1. **幅度唯一来源 = 档位表**（`infer/tiers.js`）。任何新规则必须先在 `Tiers.RULE` / 总表登记档位，**不允许在函数体内写魔法数字**（v28 的 R38 硬编码字典、v31 的 crewBias 特例都是反面教材）。
2. **`delta` 只承载方向**：`impl.neg = true` → 反向通道；幅度一律取 `SCORE[tier]`（经可信度缩放）。
3. **AI 不读真相**：决策路径只能用「该 AI 按规则应当掌握的信息」。`isHuman` 视角、上帝视角函数、DEV 面板数据**不得**进入 AI 决策；同理，AI 对**自己队友的 hostile 恒为 0**，不能拿它当「队友是否被怀疑」的判据（v31 批 3 的坑，见 §6）。
4. **不用胜率反推权重**：平衡问题只在「机制是否存在」层面解决（接线、门禁、语义），禁止以「让胜率好看」为由调数值。
5. **硬源只走 `p.known`**（读取统一经 `AIBelief.knownLockOf`）。硬源的合法来源：⑥⑩出局/驱逐揭示、④维修暴露、⑤破坏者暴露、⑦验票官、角色自身私有查验、**官方 ③ 公告**（`announce('③')` + `revealPublic`）。
   **口头汇报不是硬源**（v31 裁定）：讨论里说的「我查过 X」只做可伪造的宣称入账。
6. **Z 档在生成前拦截**（`Tactics.filterClaims`，N397~N400）：不先生成再删除。
7. **行为等价重构必须指纹不变**（v27 的八次模块化切分即以此验收）。
8. **伪随机可复现**：所有随机走 `rng.js`（种子）；新增工具同样是 `工具名 局数 种子` 的形态。
9. **语言与推理必须互为逆运算**：AI 说得出的每句话都要能被 `nlp.js` 读回同一 Claim（`test-lang.cjs` 深比较锁死）。
10. **人类与 AI 对等**：同一条 `Bridge.say()` 管道、同一套权重；不允许「玩家说的话有效、AI 说的无效」或反之。

## 6. 常见坑（都是真实踩过的）

| 坑 | 症状 | 正解 |
|---|---|---|
| `Claim` 字段名 | `IR.mk('accuse',[t])` 产出 **`targets[]`**，没有 `target` 单数字段 → 影子层 1536/1536 次返回 0（结构上死代码） | 目标解析一律 `claim.target ?? claim.targets[0]`；新增字段消费先看 `lang/ir.js` |
| Map 无槽位 | 给「尚无任何证据」的目标做探针，临时数组不进 `Map` → 前后读数恒等，静默返回 0 | 探针前先 `tEvents.has/set` 补槽 |
| **队友怀疑度恒 0** | 用 `susp(队友)` 当「卖队友」门禁 → 探针 21136 次异形发言 **0 命中** | 异形对自己队友 hostile 恒 0（认知层已知同族）。判据必须用**公开可见的处境**（被指控次数 / 已暴露 / 已揭示） |
| `const` 累加 | `uCheck` 为 const 却 `+= 80` → 72/500 局抛异常崩掉 | 效用分量声明为 `let`；批量跑必须看「异常 N」 |
| 幂等键缺维度 | `chan:id:night` 未带观察者 → 通道证据只落给座位序最前的 AI | 幂等键一律带 `observerId` |
| 测试里的假 rng | `{pick: a => a[0]}` 永远返回候选表第一项 → 抽样断言永远测不到目标条目 | 用 `g.rng` 或真实 `RNG` |
| 视角混淆 | 档位单值化 → N216 对全场 D / 对验票官 A− 写成 D（低估 6.6 倍） | 视角依赖档位用 `tiers.tierFor / magFor`（`{def, byRole, byFaction}`） |
| 旧别名残留 | 语言层产 `doc`、推理层认 `bio` → 宣称医生完全不产证据 | 口径统一在 `pipeline` 入账前归一（`doc → bio`），别在消费端逐个打补丁 |
