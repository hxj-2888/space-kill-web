## 三、为什么布局是「一条横脊 + 上下各一间」

这不是审美选择，是**约束推出来的唯一解**。`js/space.js` 的门是**按侧声明**的：

```
pharma —r→ medical —r→ verify —r→ bridge —r→ patrol —r→ repair —r→ armory
                                      ↕t / ↕b
                                    safe / dorms
```

7 间房被门的侧向串成一条链。要「语义不动、只换骨架」，就必须让这条链**水平排开**、
舰桥居中，safe 在上、dorms 在下 —— 通道全是直的短廊。
若强行折成方阵（Among Us 那种），就得给通道加折角，而折角廊会从房间中间穿过去（等于穿墙）。

船体格 `234 × 45`；水平间隔 4 格、垂直间隔 6 格、廊宽 3.2 格。

## 四、★ 三个「看起来做了、其实没做」（本批最值钱的部分）

### 4.1 走廊 pattern 从未定义 —— DOM 里有 `<rect>`，画出来是透明的

```js
'<rect class="sk-corridor" ... fill="url(#sk-floor-corridor)"/>'   // ← pattern 从未定义
```

截图一看：走廊整条是空的，露出船体内衬，读作「房间浮在虚空里」。
而 DOM 里元素在、包围盒也在 —— **614 条断言一条都不会报**。
这是 AGENTS 红线 9「元素存在 ≠ 像素可见」的**第三次**复发（前两次：`clipPath` 坐标错位、待机帧不可见）。

> 修法：`corridorHtml` 自带 `<defs><pattern>`；门禁 **SH8** 判据改成
> 「引用与定义**成对**出现」，不是"文件里有没有这段字符串"。

### 4.2 相机夹紧只做了一半 —— 半屏露出舱外

`camera()` 第一版只处理「房间比视窗大 ⇒ 夹紧」，没处理「房间比视窗小 ⇒ 居中」。
视窗 30×12 对上房间 30×11 时，y 轴因 `11 < 12` 被判"不用夹" ⇒ 相机继续跟着人
⇒ 屏幕下半截全是空船体（实测：房间只占上面 63%）。**门禁 SH4 把两条都量了。**

### 4.3 到达房间后又触发一次走动 —— `isWalking()` 恒为 true

删掉 `walkUntil` 之后保留了「phaseKey 变了就 walkTo」那一句。
但 `walkTo` 内部**已经把 curRoom 落定在终点**，于是到达后 phaseKey 又变一次 ⇒ 立刻第二次走动
⇒ 角色被拍回路径起点、相机跳一下。探针读数：`end.walking: true`，而人明明已站在查证室中央。

## 五、改写了的 5 条旧断言（逐条说明"该改断言"而不是"该改实现"）

| 旧断言 | 为什么必须改写 | 新守护对象 |
|---|---|---|
| `U2A` 入场行走 = 4 帧 + 位移 + 错峰 | `--dx/--dy/--delay` 与 `@keyframes sk-walk-in` 已整体删除（CSS 只能走直线，折线走动必须逐帧写 transform） | **U2A1** 帧动画仍在 / **U2A2** 四向选行 / **U2A3** 位移由渲染器逐帧写 |

| 移动端「所有门都在视口内」 | 整船图下 9 间房 16 扇门全在 DOM 里，其余房间在视窗外（被相机裁掉）——旧判据会报 12 条假红 | 只量**当前房间**的门；反向守卫：当前房间必须有门 |

### 6.2 ★ 反向自检暴露的问题：**6 条断言是空转的**

第一批 `test-ship` 写完，14 条全绿；跑反向自检 —— **6 条改坏了仍然是绿的**：

```
✗ SH1  ⇒ 变异未命中（替换串空格数不对）
✗ SH9  ⇒ 仍然绿      ← 判据用「文件里有没有 cam.x * TILE」，而 paintWalk 里还有一份
✗ SH10 ⇒ 仍然绿      ← 判据用「文件里有没有 for (const L of M.LINKS)」，corridorHtml 里还有一份
✗ SH11 ⇒ 仍然绿      ← 判据用「有 curRoom = roomId 就要有 !requestAnimationFrame」，兜底分支本来就带着
✗ SH13 ⇒ 仍然绿      ← 判据用「文件里有没有 CREW_BOX.w()」，crewHtml 里还有一份
```

**根因**：B 组判据落在**整个文件**上，而同一个 token 在文件里往往出现多次。
改坏其中一处，另一处还在 ⇒ 断言照样绿。

> **本批立的规矩（写进 `test-ship.cjs` 文件头）**：
> **B 组判据一律落在函数体内部**（`bodyOf(src, 'function xxx(')`），不许落在整个文件上。

修完再跑：SH11 又失败了 **3 次**，每次都是判据被变异绕过（"看顺序"→"看括号配平"→"逐个检查每一处"），
最后一条还**把基线判红了**（因为"算不出路径时直接落定"合法地不在 if 里）。
最终判据：把两种**合法的直接落定**枚举出来，其余一律判红。

> 教训：**「反向自检失败」经常是判据写错，不是实现错。** 但也不能因此把判据放宽到恒真 ——
> 本批 SH11 的 4 个版本里，前 3 个都是"被绕过"，第 4 个才是"真的守住"。
