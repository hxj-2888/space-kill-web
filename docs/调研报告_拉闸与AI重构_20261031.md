## 五、AI 风险/收益表（参照 SKTrait 的效用函数）

### 5.1 现状：全是阈值 if，没有统一权衡

新返航录的 AI 决策散在 `aiCrew()` / `aiTickAlien()` 里，形式是"条件命中就做"：

- 异形挑目标：`目标评分 = 距离 − 12×(有人看着) + 12×(在做任务)` → 有加权，但**没有代价项**
- 拆保安：`secbotRaidOk()` 是硬门槛（2 名队友 + 共同目标），没有"值不值得"
- 合闸：`_lightGo` 名额制，没有"谁去最划算"
- 修故障：按距离取最近 2 人，没有"修的时候会不会被刀"

### 5.2 参照对象（`过渡版` 分支）

```js
// 过渡版 js/ai/decide.js
const TR = global.SKTrait;                       // 性格轴声明（档位参数唯一真源）
uDestroy = 100 × pressure − 风险项 ± 性格;        // 破坏的效用
uAct     = threatTop × 衰减系数;                  // 攻击的效用
/* v22 性格化行动门槛：激进 30 / 保守 70，行动门槛与性格反向联动 */
if (Dg < actLine) continue;
```

关键设计不是"公式"，而是三点纪律：
1. **性格是声明层**（档位 0–100），不散落在 if 里；
2. **同一套效用比较所有候选动作**（不是按顺序 if-return，而是打分取最高）；
3. **风险项显式**（被目击概率 × 暴露代价），而不是"有人看着就跳过"。

### 5.3 新返航录的落地方案

**性格轴（每人抽一档，跨局固定）**：`aggr 激进 / caut 谨慎 / soc 社交 / cur 好奇`

| 轴 | 影响 |
|---|---|
| `aggr` | 出刀距离容忍、拆保安意愿、拉闸意愿 |
| `caut` | 弃修逃跑阈值、靠近保安距离、单独行动意愿 |
| `soc` | 会议发言率、替人辩护率、跟票率、质疑报案率 |
| `cur` | 搜尸意愿、离开任务点绕路查看的意愿 |

**效用表（异形侧 6 个动作、人类侧 5 个动作）**：

| 方 | 动作 | 收益 | 风险 |
|---|---|---|---|
| 异形 | 出刀 | 清人进度（剩余人类越少收益越高） | Σ(目击者 × 可见性) × 确证代价 |
| 异形 | 拉闸 | 断电视野压制（人类视野 7→2.8） | 目击风险（改 md 改动 3 后**直接确证**） |
| 异形 | 破坏 | 人类进度 −5 的期望 | 在场人数 × 被目击 |
| 异形 | 拆机器人 | 保安失效（人类少一层保护） | `saw_bot` 确证 + 拘留 |
| 异形 | 钻管道 | 位移收益 | 管道口被目击 = 确证 |
| 异形 | 报告拖时间 | 会议扣夜 | quick_report 嫌疑 |
| 人类 | 做任务 | +1/+2 进度 | 站桩 8–15 秒不能动 |
| 人类 | 修故障 | 避免 −5 | 同上 + 故障点通常是"钩子" |
| 人类 | 合闸 | 恢复视野 | 走向配电室的路上单人 |
| 人类 | 搜尸/取证 | 信息 | 停留时间 |
| 人类 | 施救/拖尸 | 保住人数 | 拖尸速度 2.7 格/秒、留 bodyMoved |

**实现形态**：新增 `js/ai/utility.js`（纯函数、无 DOM、可单测），暴露

## 六、性格声音系统（voice）

### 6.1 现状：15 人共用模板池

`startChatter()` 里所有 AI 的台词来自 `pickLine(a, [...])`——**按场景分支，不按角色**。
实测后果（太空杀那边量过）：句子多样性 11.8~12.6%，最高频单句被重复 800~900 次。

新返航录这边更粗：15 个名字只影响 `salt`（防重复），不影响"说什么、怎么说"。

### 6.2 移植方案（三件套）

1. **性格 → 说话风格**：`aggr` 高的人短句、命令式；`caut` 高的人带保留（"我信息不够"）；`soc` 高的人爱追问/辩护。
2. **话题表（topic）**：按"这个人此刻合法知道什么"生成，`probe()` 取料 → `line()` 成句；取不到料返回 `null` 落回通用池。
   - 例：`sawAgent`（见过谁在哪）→ "我 02 那一夜在食堂，只碰到 07 一个人。"
   - 例：`knownTarget`（确证某人）→ "我确定 05 是异形，我亲眼看见他拉的电闸。"
   - 例：`lootLog`（自己搜过谁的尸体）→ "09 的包是我搜的，里面只剩一张申请单。"
3. **代价进发言**：异形撒谎成本 → 发言更"绕"（先铺垫后指控）；人类有确证 → 直给。

**纪律**（照抄 voice.js 的四条）：
- 声明层是唯一真源（性格档 → 话题集合，不在台词里另写 if）
- 只说自己有权知道的（不读 `alien`、不读队友表）
- 取不到料就闭嘴（不制造噪声）
- 新增角色能力必须同时加话题，否则 audit 报错

### 6.3 门禁怎么测

- `voiceDiversity`：1000 局里不同句子占比（目标 > 30%）
- `voiceNullRate`：返回 null 的比例（目标 20–40%，太高=没料，太低=硬编）
- 每个性格档至少 3 条独有句式

## 七、电路维修「没人做」的核查

### 7.1 代码层：没有硬编码禁止

```js
// js/game.js:2949  修好电路维修 → 全船照明恢复（唯一副作用）
if(p.room==='power'&&p.label==='电路维修'&&!G.powerFixed){ G.powerFixed=true; ... }
// 任务分配 (js/game.js:96)  每个 AI = 1 个随机 hard + 3 个随机 normal
tasks:[hardPts[Math.floor(Math.random()*hardPts.length)]].concat(shuffle(normalPts).slice(0,3))
```

电路维修是 8 个 hard 之一 → 每人有 1/8 概率被分到。**任务本身可达、可完成、可计数**。

### 7.2 真正的原因（三个叠加）

1. **路程成本**：配电室在房间左半、单门进出，从右半（军械/娱乐/监控）过去 18–24 秒；
2. **暗房惩罚**：`power.light==='dark'`，站桩 15 秒期间视野只剩 2.8 格，AI 的 `taskThreat()` 一旦看到已知异形在 7 格内且"赶不完"就 `fleeTask()`；
3. **收益不可见**：修好只恢复照明，**不加进度分以外的任何东西**，而 AI 的效用里"照明"这一项根本不存在（`G.powerFixed` 只影响拉闸时长）。

### 7.3 实测结果（1000 局 · 2026-10-31，seed 20261031）

已补遥测 `tasksByPoint` 并跑完，**结论与预期相反**：

| 任务点 | 难度 | 每局平均完成次数 |
|---|---|---:|
| 氧气循环 | hard | 1.508 |
| 监控墙重连 | hard | 1.450 |
| 手术台校准 | hard | 1.444 |
| 变压器换芯 | hard | 1.433 |
| 靶道校准 | hard | 1.426 |
| 引擎组同步 | hard | 1.410 |
| **电路维修** | **hard** | **1.405** |
| 货架校准 | hard | 1.354 |
| 普通任务（18 个） | normal | 1.114 ~ 1.188 |

**电路维修在 26 个任务点里排第 7 高，不是"没人做"。** 它甚至高于全部 18 个普通任务。

- hard 点整体（1.35–1.51）高于 normal（1.11–1.19）是**分配结构**决定的：每人任务表 = 1 个随机 hard + 3 个随机 normal，
  8 个 hard 点分摊 15 次抽取、18 个 normal 点分摊 45 次抽取，hard 点单位被选中率高得多。
- 所以你看到的"完成极低"更可能是**现场观感**：配电室是暗房 + 单门，AI 走进去 15 秒站桩时你看不到，
  而它一旦被 `taskThreat()` 判定"赶不完"就会弃修（这一条在数据里体现为 1.405 略低于其它 hard 点约 0.05，属噪声内）。

**处置：按你的要求先不改行为。** 遥测已进 `tools/mc-report.md`，后续若要动，优先动"配电室暗房 + 单门"的可达性，
而不是给任务加收益。
