# 推理库模块化与效用清单（2026-09-11）

原则：**只保留能改变 AI 判断的证据通道**（N 层为主），按 100 局蒙特卡洛实测读数分四档处置；
`channels.run.js`（485 行单文件）按证据域拆成 6 个模块 + 1 个共享谓词层，执行器退化为纯注册表驱动。
本文只做方案与清单，不改代码——任何接线/删改都会改变写入集合 ⇒ 指纹必变 ⇒ 必须随批跑
`node tools/mc.cjs 500 1` 验收（对照基线：人类 36.0% / chan_wired 38 / evidence_divergence 0.334）。

---

## 一、模块化目标结构

```
js/infer/
  registry.js            不动：RANK / EXPERTS / HARD_ROUTE / ROLES_EXPERTS / G_EXPERTS
  moe.js                 不动：route / arbitrate / write(Raw) / absorb* / shadow
  channels.run.js        瘦身为执行器（~120 行）：合并各模块 GATE_IMPL 片段 + runChannelsAll + mountedIds
  predicates.js          新增：跨域共享谓词（现散在 channels.run.js 顶部的 8 个函数）
  modules/
    e1-destroy.js        破坏算术族   N04~N22 / N95~N100     （20 条，expert:'E1'，universal）
    e2-infection.js      感染记忆族   N139 / N141 / N149 / N407（医生私有，4 条）
    e3-ballot.js         票型对账族   N182 / N216 / D03 / N188（验票官私有，4 条）
    e4-verify.js         查验自证族   A01 / A02               （2 条，E4）
    e11-network.js       攻击反馈族   N306 / N318 / N403~N405（攻击方私有，5 条）
    e56-protect.js       保护结算族   N401 / N406             （④ 暴露 / 濒死对账，2 条）
```

`predicates.js` 收编 8 个跨域函数（`aliensAlive / T10 / dmgT / distNext / onceChan /
patrolSpentPublic / blockCases / strongPromises`）——它们目前是 channels.run.js 里唯一的
耦合点，拆模块前必须先抽出来，否则六个模块互相复制。

**不动的东西**：`channels.data.js`（506 条资产保持全量入库，它是「可追溯工作清单」，
dormant 字段失真另行修复——见 §四 O7）；`speakable / pipeline / visible` 本就是单职责小模块。

## 八、一句话

**38 条接线里真正在干活的约 21 条（A+B 档），1 条（N04）在制造统计噪声，16 条是诚实的「稀有事件备件」**。
模块化不是把 506 条都变成代码，而是：执行器归一（channels.run 瘦身）、判据按证据域分家（6 模块 + 谓词层）、
效用分级挂账（A/B 保留、C 改造、D 挂起写明前提）、未接线存量按「一次 emit 解锁一族」的顺序通电。
