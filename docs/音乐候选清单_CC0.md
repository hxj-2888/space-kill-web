## 关于「绝望」这个名字

**不存在一个叫《绝望》且可自由使用的曲目。** 名字接近的知名曲目全部是商业版权音乐，
**不能打包进公开分发的游戏**（哪怕只是背景音乐）：

| 曲名 | 出处 | 作曲 |
|---|---|---|
| 絶望ビリー | 动画《死亡笔记》ED2 | MAXIMUM THE HORMONE |
| Desperatio | 动画《魔法少女まどか☆マギカ》OST | 梶浦由記 |
| 絶望 | 《弹丸论破》系列 OST | 高田雅史 |
| Despair | 《BLEACH》OST | 鷺巣詩郎 |

因此下面按「**氛围等价物**」来选：悬疑 / 压抑 / 绝望 / 太空恐怖。

## 落地建议

1. **单曲方案（改动最小）**：从 A1 里选一条直接替换 `audio/music-space-ambience.ogg`，
   按现有做法做响度归一（CREDITS.md 记录为 -18 LUFS）与首尾淡入淡出。
   最贴合题材的候选：**Space Graveyard**、**Lost in a bad place**、**Post Apocalyptic Wastelands**。
   字面最接近"绝望"的：**Chasing Despair**。
2. **双层方案（氛围最接近"绝望的太空"）**：A1 一条作氛围底 + A3 一条（如 Eternal Sleep 或
   Chasing Despair）作情绪层，两轨在游戏内混音。代价是体积翻倍、需多一个 `<audio>` 同步循环。
3. 选定后请把「曲名 / 作者 / 页面链接 / 许可」补写进 `audio/CREDITS.md`，保持该文件的来源留档作用。
