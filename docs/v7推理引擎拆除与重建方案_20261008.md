## 1. 拆除前必须知道的一件事：引擎已经在采集角色私有观察，但把它们全部丢弃

这是本次拆除**最重要的发现**，它改变了整个方案的性质。

`engine.js` 与 `engine/steps.js` 现有 **10 处** `MoE.absorbPrivate` 调用，按 `own:<Role>:<what>:<night>` 结构化前缀写入私有流水：

| own: 类别 | 60 局条数 | 规则依据 |
|---|---|---|
| `own:rescue:dying` | 352 | 4.6.1 濒死清单 |
| `own:alien:mark` | 260 | 5.x 感染标记 |
| `own:bodyguard:guard` | 225 | 4.11 守卫 |
| `own:sheriff:patrol` | 165 | 4.4.4 巡逻 |
| `own:crew:repairN` | 162 | 4.1.1 协助维修 |
| `own:engineer:repair` | 161 | 4.3.2 维修 |
| `own:detective:check` | 125 | 4.7.1 查验 |
| `own:rescue:mark` / `own:bio:mark` | 141 | 4.5 标记清单 |
| `own:bodyguard:hit` | 58 | 守卫结果反馈 |
| `own:xeno:check` | 52 | 6.x 蛰伏 |
| `own:bio:antibody` | 7 | 4.5.2 抗体 |
| 合计 | **1756** | — |

**但 `moe.js` 的 `absorbPrivate` 把 delta 写死为 0：**

```js
AI.addEvent(g, viewerId, target, 0, false, src, kind || 'fact', tier || null, ...);
```

实测确认：**这 1756 条角色私有观察的 `delta` 取值集合 = `{0}`**，且把某条 `own:` 的 delta 从 0 改成 30 后，`suspOf` **从 0.00 变为 0.00——零影响**。

**结论：神探知道「我查过 X」、保镖知道「我守了 Y 整夜」、医生知道「Z 有假标记」，这些信息在引擎里真实存在、结构化、有角色归属，但在估值层被完全丢弃。**

> 所以本次拆除**不是**「砍掉推理能力」，而是**停止丢弃已经采集到的角色推理素材**。旧引擎唯一的输出（`suspOf` 0.3378 / `dangerOf` 0.4999）实测是反向或随机的——它没有可保留的推理成果，只有 1756 条被扔掉的素材。

## 2. 为什么「发言对齐 + 激活通道 + 结算分数」这条路必须整条放弃

四条独立证据，全部指向同一结论：

### 2.1 结算分数是反向的

| 量 | AUC | 判读 |
|---|---|---|
| `dangerOf`（投票实际读它） | **0.4999** | 纯随机 |
| 全量负向证据（`suspOf` 底层） | **0.3378** | **反向** |
| `actF` 活跃度 | 0.3347 | 强反向 |
| 被质询次数 | **0.2020** | 极反向 |

**证据越多越清白**——人类目标人均 2.05 条证据 vs 异形 0.94 条（2.19×）。因为异形低调不被追问，人类天天被指控被质询。「结算分数」在度量「显眼度」，不是在度量「威胁」。

### 2.2 通道库边际贡献 +0.002（项目自己的消融实测）

`full` 0.500 vs `off` 0.498；top1 从 61.8% → 63.8%（**变好**）；gate 求值 496,144 → **0**。证据构成里 claim 占 97.4%、通道 universal 仅 **0.7%**。

### 2.3 激活的机制大部分是空转

| 机制 | 实测 |
|---|---|
| 仲裁差一档 / 差两档 | **0 / 0**（65529 组输入，从未触发）⇒ `verifyQueue` 恒空，其消费点是死码 |
| 通道总表 506 条 / 已挂载 | **44 条 = 8.7%** |
| `convert` 转职 | 1252 请求 / **0 成功** |
| `craft` 铸造 | **0 请求**（artisan 无席位） |
| 承诺结算 | hit=0 / miss=0 |
| 路由重合度 | **0.92**（克隆体） |
| 注意力调制 / 闸门 / 缓存 | 偏ρ = +0.126 / −0.055 / +0.042（**对胜负无解释力**） |

### 2.4 「发言对齐」产出的是复读，不是推理

- 发言去重后仅 **25%**（6096/24406），单句最高复读 **332 次**
- 人类 9 角色 accuse 23~28% / ask 52~55%，**统计不可区分**
- 角色投票命中率挤在 **31%~42%**
- 治理规范的「机制-指标背离」实例：`ask` 通道与人类胜率**正相关 +0.500**，却是**反向度量（AUC 0.2705）**

### 3.3 引擎侧改造（保留行为，去掉推理依赖）

**10 处 `MoE.absorbPrivate` 调用点全部保留**，但改写为直接写新素材结构：

```js
// 旧：if (global.MoE && global.MoE.absorbPrivate) global.MoE.absorbPrivate(g, p.id, t.id, `own:detective:check:${g.night}`, 'fact');
// 新：
Vision.record(g, p.id, { kind: 'check', target: t.id, role: rec.role, night: g.night, rule: '4.7.1' });
```

这样**引擎一次都不用改逻辑**，只换记录函数名——**拆除的改动面因此从"引擎重写"降为"引擎换接口"**。

## 4. 新架构

### 4.1 三段式（无评分、无通道）

```
① 采集  js/ai/vision.js     —— 角色私有观察（复用现有 15 类 own: + 新增）
② 推理  js/ai/inference.js  —— 观察 + 记忆 → 推理素材（定性，非分数）
③ 消费  decide.js / speak.js —— 素材驱动决策与表达
```

### 4.2 为什么不做分数结算

旧模型：`E 通道 → 加权累加 → project → 分布 → S/Dg`，五层，每层都引入偏置。
新模型：**素材是定性的、带出处的、可追溯的**：

```
素材 = { 观察, 角色, 规则依据, 夜次, 方向 }
```

- 神探素材：`{我查过 7 号，他自称工程师}`（可公开，因为可兑现）
- 保镖素材：`{我守了 9 号整夜，他没遇袭}`（可公开，因为有代价）
- 医生素材：`{10 号的标记已滞留 4 夜，大概率是假标记}`（可公开，因为 4.5 规则背书）

**决策读素材而非分数**：警长开枪 = "有素材指向谁"（离散、可解释），而非 "D9=72 > θ+35"。

### 4.3 威胁判断改为「素材计数 + 硬源优先 + 可见度去偏」

沿用已验证的 A7 口径（AUC 0.5586，种子隔离验证集 0.5737）：

```
优先序：
  1. 硬源（known 硬锁 / checkPool / crewChecks）  AUC 1.0，权重压倒性
  2. 角色私有素材（own:*，红线下必入账，豁免注意力闸门）
  3. 公开软素材 —— 剔除 ask/accuse 两族，除以可见度
```

**不做**：把素材折算成单一分数再比较。

### 4.4 各角色应有的推理（全部来自规则正文，且**素材已存在或可低成本获得**）

| 角色 | 推理 | 素材来源 | 旧引擎状态 |
|---|---|---|---|
| 神探 | 查验→定基调；**公告转化** | `own:detective:check` 已有 | delta=0 被丢弃 |
| 验票官 | 票型→责任链 | `g.voteHistory`（引擎已有，AI 未读） | 无 |
| 警长 | 威胁→射击；夜袭复盘 | `own:sheriff:patrol` 已有；`gunAttackers` 字段已存在 | delta=0 被丢弃 |
| 猎手 | 嗅探推理 | `p.sniffLog` 字段已存在 | 无 |
| 工程师 | 维修→暴露权衡 | `own:engineer:repair` 已有 | delta=0 被丢弃 |
| 保镖 | 守卫结果反馈 | `own:bodyguard:guard` + `own:bodyguard:hit` **已有** | delta=0 被丢弃 |
| 医生 | 标记真伪（R7 回流） | `own:bio:mark` 已有 | delta=0 被丢弃 |
| 救援 | 濒死清单归因 | `own:rescue:dying` 已有 | delta=0 被丢弃 |
| 船员 | 双查验证式 | `p.crewChecks` | 唯一有真实决策 |
| 异形/外星人 | 清除威胁 | `own:alien:mark` 已有 | delta=0 被丢弃 |

**11 个角色中 8 个的推理素材引擎早已在采，只是被丢掉。**
