## 三、三个工具的真 bug（都已修）

### 1. `text-align.cjs` — 正文版本写死 v6.6

旧实现把 `docs/_v66正文_提取.txt` 与 v6.6 的 PDF SHA 写死。换版后拿**旧抽取件**对账**新声明层**，
4.13/4.14 等新条款一律判「查无此条」——**假 P0**。

现改为按版本分文件、各自带指纹：

```js
const RULES_VERSIONS = [
  { id: 'v1preview1.0', extract: 'docs/_返航录v1preview1.0_提取.txt',
    pdfSha: 'E24B543CB1D0FA15463C260248C6CB2F116250BFB490236272D1E2A1AA1FC166', ... },
  { id: 'v6.6', ... },
];
```

选择顺序：`--extract` 参数 > 环境变量 `SK_RULES_EXTRACT` > v1preview1.0 > v6.6（**回退时打印醒目告警**）。

**抽取件不在库**（gitignore），缺件时会打印当前版本对应的重建命令。
重建命令：
```
python -c "import pdfplumber,sys; d=pdfplumber.open(sys.argv[1]); sys.stdout.write(chr(10).join(p.extract_text() or '' for p in d.pages))" <PDF> > docs/_返航录v1preview1.0_提取.txt
```

### 2. `text-align.cjs` — 条款索引正则的零空格回溯

旧正则 `^(\d+\.\d+(?:\.\d+)?)\s*(\S.*)$` 的 `\s*` **允许零个空格**，
于是独占一行的 `3.3.10` 被回溯拆成 `3.3.1` + `0`，真条款位置错落到后文引用它的那行，
导致 3.3.10 的 ②③④ 全部「查无此项」。

现改为：`^(\d+(?:\.\d+)+)(?:\s+(.*))?$`。

### 3. `mc.cjs` — `null` 取属性中断整份报告

`moe` 缺席时 `metrics.B_仲裁` / `C_影子` 为 `null`，代码直接取 `.arb_input_total` 抛 TypeError，
**整份蒙特卡洛报告被截断**。现加空值守卫。

### 4. `card-audit.cjs` — 输出目录写死

写死 `C:/Users/ASUS/AppData/Local/Temp/opencode/`，该目录不存在即 ENOENT。
现「存在则用，否则回退系统临时目录」，并打印落盘位置。

### 5. `build_site.py`（附件站）— 只读文件删不掉

`site/` 下 PDF 带只读属性（被整目录复制过），`os.remove` 抛 WinError 5。
现删前先 `os.chmod(0o666)`。

## 五、附件站纳入 CI（本轮最重要的一处修复）

### 问题

线上 `space-kill.pages.dev` 的三份新 PDF 返回 **`text/html`、23397 B、首字节 `<!DOCTYPE html>`**
——是 SPA 回退，不是 PDF。而仓库里文件齐全。

### 根因

`space-kill` 这个 Pages 项目**没有 CI**。`deploy.yml` 只部署游戏站
（`tools/deploy-pages.cjs` 的 `SITE_ENTRIES` 不含 `attachment-site/`），
`attachment-site/README.md` 写明「由 Cloudflare Pages 直接托管 `site/`」——即**手动部署**。

### 现在的保护（`deploy.yml` 新增两个 job）

| job | 作用 |
|---|---|
| `deploy-attachment` | `wrangler pages deploy attachment-site/site --project-name=space-kill` |
| ↳ 部署前门禁 | 跑 `build_site.py` 重建 `site/`，与提交版 `diff -r`，**不一致即失败**（防产物与源分叉） |
| `smoke-test-attachment` | 首页 / `rules.html` 可达 + **四份 PDF 必须 `application/pdf` + `%PDF` 首字节 + >100 KB** |

最后那条冒烟是这次踩坑的直接产物：**只看 HTTP 200 会被 SPA 回退骗过去**。

已实证跑通（run `39583002721`，5 个 job 全 success）。

**锚点不能盲抄名字**，每条都核对过正文标题。
