| 仪器 | 新增「挤出次数 / 在册数分布 / 出册目标的后续再入率」 |

### 5.2 显著性过滤（连续权重，非硬阈值）

```
salience = 档位分值(SCORE[tier]) × 私有度权重 × 与己相关度
```

| 分量 | 取值来源 | 说明 |
|---|---|---|
| 档位 | `Tiers.SCORE[tier]`（已入账事件的 `tier` 字段） | A35/B20/C10/D5，±2 —— 已是连续可乘的量 |
| 私有度 | `vis` 类别 → 权重（hard/private/public → 1 / 1 / <1） | 硬源与私有源**不进此乘法**（=1，红线 3） |
| 与己相关度 | 目标与观察者的关系（是否被其指控过 / 是否同一私聊对 / 是否其查验目标） | 现成字段：`p.accuseHistory` `p.lastInvite` `p.checkPool` |

**落地口径（解决「低于门槛不入账」与「必须连续」的表观冲突）**：
- 把 salience 实现为 **入账强度系数**（乘在 `delta` 上，连续），而不是布尔开关；
- 「不入账」的职责交给 **5.1 的容量挤占**（显著性最低者出册）—— 这本来就是连续的（比谁低）；
- 若仍需一个门槛，用「当夜 salience 排名的分位数」这类**由分布决定的连续判据**，禁止绝对常数硬阈值（违反噪声章 20.1，也会「制造必然」）。

### 5.3 非均匀遗忘（近因 + 首因，已拍板）

| 项 | 现状 | 改造 |
|---|---|---|
| 现状 | `belief.js:82-85 claimDecay`：`kind==='fact'` 恒 1（硬源/事实不衰减）；其余 `Math.pow(0.85, age)` **均匀** | 保留 fact 豁免（红线 3 的硬源侧） |
| 近因 | — | `age` 小（≤1 夜）的系数抬升 |
| 首因 | — | 该观察者对某目标的**首条**事件给残留系数（第一印象） |
| 首因的载体 | 事件无「首条」标记 | 建议：`addEvent` 时若该 `(viewer,target)` 首次入册则打 `first:true`；**与关注名单交互**：目标出册后首因标记随之消失（忘光了自然没有第一印象）—— 这正是要的语义，需在实现时明确 |

## 7. 四条红线（与现行红线的合并清单）

1. **注意力是连续权重，不是硬阈值** —— 显著性做成乘性系数；「不入账」交给容量挤占（本身就是连续比较）。
2. **不设靶** —— 分叉度 / AUC / `tEvents` 条数只观测、不进 gate；批 6′ 的「>90% 怀疑线」是怀疑线不是靶。
3. **硬源与私有源不受注意力和容量限制** —— `p.known`（`knownLockOf`）现状已豁免；私有源字段
   （`checkPool`/`crewChecks`/`markEverSeen`/`dyingSeen`/`antibodyFired`/`attackLog`/`bulletLog`/`repairTotal`）
   不得被关注名单挤出。
4. **异形→外星人推断仍锁三道** —— 留单体层 / 不进普适层 / 幅度 ≤C+（专项文档 4.2，批 3.5 已用断言锁死）。

并保留现行架构红线：幅度唯一来源 = 档位表；`delta` 只承载方向；AI 不读真相（除规则明文的合法视野，如 3.3④ 异形标记清单）；
行为等价重构必须指纹不变；语言与推理互为逆运算；人类与 AI 对等。
