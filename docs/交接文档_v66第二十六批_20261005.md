
⚠ **脚本里三个坑，改动时务必保留**（都是实测踩出来的）：

1. **`apply_redactions()` 会清掉页面字体注册** —— 每次 `insert_text` 前必须重新 `insert_font`。
2. **不能用 PDF 内嵌的 MiSans 子集字体**：子集只含原文字形，且 PyMuPDF 重嵌时不生成 ToUnicode ⇒ 实测改写字**既不渲染、也提取为 `\x00`**（不可检索/复制）。改用系统中文字体（`msyh.ttc`），再 `doc.subset_fonts()` 把体积从 29 MB 压回 0.69 MB。
3. **遮盖矩形横向不得外扩**（`PAD_X = 0`）：PyMuPDF 按「字形与矩形相交即删除」处理，外扩 0.6pt 会蹭掉紧邻的前一个字（实测 p34 的 `4.3.1-九` 丢了首字 `4`）。
4. **同行后文不会自动右移**：中段增宽必须遮盖至**行尾**并把「新字＋后文」整行重排，否则压字。**块级选行还须加横向条件**（表格标签列与内容列 y 相同，实测 R6 曾选中标签列「神探」，导致遮盖退化成 1pt 宽、新字压在旧字上）。
