# 新返航录 · 返航录V3

> **11 人类 vs 4 异形**的实时太空船对抗网页游戏（试玩版）。
> 零依赖前端 · 无构建步骤 · 双击 `index.html` 即玩 · 单机 AI 托管对局

- **版本**：返航录V3（`package.json` 语义化镜像 `3.0.0`）
- **仓库**：[GitHub](https://github.com/hxj-2888/space-kill-web) · [Gitee](https://gitee.com/hxj-2888/space-kill-web)
- **许可**：代码 MIT；音效 CC0；场景素材 CC-BY 4.0（详见[素材与许可](#素材与许可)）

## 快速开始

| 方式 | 做法 |
|---|---|
| 直接运行 | 双击 `index.html`（推荐 Chrome / Edge；手机请横屏） |
| 本地服务 | `npm start` → <http://127.0.0.1:5173> |
| 回归门禁 | `npm test`（需要 `playwright-core`，见[开发与测试](#开发与测试)） |
| 蒙特卡洛 | `npm run sim`（1000 局 AI 对 AI，输出 `tools/mc-results.json` 与 `tools/mc-report.md`） |

开始页选择「人类」「异形」进入对局，或选「旁观者」作为**第 16 人**观战；每局仍是 15 席（11 人类 + 4 异形），全部由 AI 托管，旁观者不参与任何判定。

## 玩法概要

- **人类**：完成自己的 4 个维修任务（1 高难 + 3 普通），并和队友把全船维修进度推到 45 分；或清剿全部异形。
- **异形**：出刀（含对队友）、开枪、钻管道、拉闸、停摆机器人，并可用**每夜一次的破坏技**选一处非会议室舱室下手，削减人类数量。
  异形之间**互不知道身份**；AI 不读取任何队友信息，目标、会议指控和投票都不按阵营过滤，
  因此异形也可能攻击或投掉同类。人类只有目击异形专属行为（出刀 / 钻管道 / 破坏设备 / 停摆机器人）
  才会把对方列为嫌疑人。
- **物资申请单**：每人 4 个任务（1 高难 +2 分 / 3 普通 +1 分）。积分到 3 / 5 只生成「待领取申请单」；
  必须回中央会议室**圆桌**按 `E` 站桩 3 秒领取一张申请单；再到军械库 / 医疗间的**专用补给点**
  按 `E` 消耗 1 张申请单换子弹或医疗包。未领取时补给点会明确拒绝。
- **会议**：发现尸体按 `R` 报告，或点击尸体搜尸后报告；自由发言阶段 AI 会盘口供、质疑与作证，随后投票驱逐并**公布身份**。
- **设施**：配电室电闸（全船熄灯；**电路维修完成后，再拉断电闸要 6 秒**，恢复供电仍是 3 秒）、
  监控室 10 路画面（10 间舱室全覆盖，含仓库；显示真实角色，不是小点）、
  医疗机器人（**每夜 2 次电量，每次拉起要 5 秒**，耗尽后显示电量耗尽）、
  保安机器人（**10.5 格 / 180° 半圆**内**先近身追捕、压制、再押送到军械库角落**，拘留 **30 秒**，每夜最多 2 次）、
  中央会议室圆桌申请单、军械 / 医疗专用补给点，以及 22 扇**自动门**（无人闭合、靠近滑开，关门时阻挡移动与视线）。
  两台机器人会在医疗间 / 军械库内巡逻（**医疗机器人 9 点、保安 4 点**），拘留、施救、交互都按巡逻中的实时位置判定；
  医疗机器人的施救半径是 **6 格**（虚线圈 = 6 格圆 ∩ 医疗间），加密后的巡逻线覆盖整座医疗间；
  保安 / 医疗机器人都有装甲，可被出刀或开枪摧毁，保安机器人会反制拘留攻击者。
  **机器人被摧毁、有人被拘押都不再有全局播报**，只能靠火花 / 警报特效与在场目击者自己判断。
- **硬掩体**：房间内的家具 / 培养罐 / 货箱是真实阻挡，不能穿过；掩体布局保证每个房间有连通绕行通道，
  不存在夹缝走不过去或掩体制造的尽端死路（门禁 `coverAudit()` 零夹缝 / 零死路）。
  家具表面材质由 `tools/gen-materials.py` 用本地 SDXL 生成（金属板 / 钢板货箱 / 织物 / 复合台面 / 医疗白板），
  统一降饱和冷调到地板与墙面同一色温；Blender 侧补齐倒角、包边、螺栓、散热百叶、地面警戒框与接地软阴影，
  避免“方块贴纸感”。
- **门是顶面视角**：自动门只画「门的最上面一层」——横门 / 竖门只是旋转 90°，从上下左右看都一样，
  不再露出一整块门板正立面（Blender 端也去掉了门楣与高处灯带）。
- **断电门禁**：断电期间，**全船每一扇门（含会议室三门）在有人靠近时都要先扫描 2 秒**才放行（红色扫描线），
  人离开后重新上锁；恢复供电立即解除扫描。直到电力恢复为止，每次过门都要重新等这 2 秒。
- **亮房整间可见**：站在亮着的舱室里，**整间房的人都直接可见**（家具 / 掩体不再挡住“看人”，
  与迷雾整屋揭开一致）；暗房或熄灯房间才退回 7 格手电锥 + 近身视野。
- **走廊默认有灯**：未断电时走廊和亮房一样默认开灯——站在亮走廊里能看清**整条走廊**上的人，
  不再依赖手电朝向；从亮舱看进相连走廊按视线结算。断电后走廊灯全熄，才退回手电锥 + 近身视野。
- **事件流与复盘**：整局记录 `G.events`——谁在哪出刀 / 开枪 / 死亡（含凶器与凶手）、谁完成哪个任务或修好故障、
  谁钻管道（起点→终点）、谁拉闸 / 合闸、谁拖起 / 放下谁、谁搜了谁、谁领取 / 兑换物资、谁被拘留，
  以及每场会议、每句发言、每张票、驱逐结果与“尸体被拖离医疗间”的反常行为。结束后可**保存回放**（JSON：事件流 + 每 0.5 秒的 15 人位置帧 + 身份表），
  也可以直接在游戏内打开**复盘页**：拖时间轴看 15 个席位在船上移动、点事件高亮对应舱室；
  待领申请单会常驻 HUD 提示并在小地图给圆桌金色脉冲；
  开始页还提供「载入回放」，之前保存的文件可以随时重开复盘。
- **异形视野**：异形拿**和人类同款的手电筒**（7 格 / 60° 锥形），不再有全向远视野；
  只有自带近身感知半径大三分之一（人类 **2.8 格** → 异形 **3.11 格**），黑暗里更容易察觉贴到身边的人。
- **旁观者**：第 16 人不占席位、不可交互/搜尸/收尸/投票，但拥有全知视角与 9 格/秒的穿墙幽灵相机，
  HUD 会切成旁观者面板并常显全知总览；会议中额外保留**「跳过讨论（旁观）」**按钮，只快进讨论，不发言也不投票。
  **0 号星尘由 AI 完整托管**（独立发言、投票、行动），DEV 名单标「AI」而不是「你」。
- **设置**：开始页与暂停面板都能打开设置——音乐 / 音效音量（写 localStorage）、暂停 / 继续、退出到开始页。
- **任务提示**：自己的任务点不再套黄色虚线框，而是**让所在家具本体发出金色脉冲**
  （从烘焙底图裁出该掩体的像素做 `screen` 叠加），目标读起来是“那台机器在闪”，不是“框里有东西”。
- **破坏与抢修**：每个异形每夜一次破坏技，按 `H` 选择除中央会议室外的任意舱室，抵达后损毁该舱室设备；
  故障有 30 秒窗口，人类或异形站在设备旁按 `E` **连续维修 10 秒**即可排除（移动会打断）。
  30 秒内未修完且天还没亮，维修进度 **-5**；天亮时未修完的故障不追罚。幽灵不能破坏；
  **人类幽灵**（玩家与 AI）可以修任务/故障（1.6×，最多 2 分任务进度），**异形幽灵不执行任何维修/任务**。
- **站桩维修**：任务维修与故障维修都必须站在设备旁；移动会立即打断并重置计时，不再是“边跑边修”。
- **地图**：**10 间舱室**（新增 504 格**仓库**：位于中央会议室正上方、10 格中等长度通道连接、单门、可被监控室看到；
  中转间改为**食堂**并换掉全部内置物品与地板贴图；食堂↔娱乐室的通道已封闭）· **26 个维修点**（8 高难 + 18 普通）·
  **6 个管道口**（引擎 / 监控 / 军械 / 仓库 / 食堂 / 医疗间）· 22 扇自动门 · **59 件硬掩体**（桌椅/柜子/机器全部真实阻挡）；
  整船边界 **98×94**——仓库与加长走廊（食堂↔医疗、桥楼↔食堂、中转↔医疗、军械↔医疗）都是扩出来的，不是硬塞进会议室。管道只有异形可用，人类无法打开。
- **移速**：所有活人统一 **4 格/秒**（原 5 格/秒）；拖尸 **2.5 格/秒**，玩家幽灵 6.5 格/秒是显式例外。
- **任务时长**：高难统一 **15 秒**（配电室的**电路维修 18 秒**），普通统一 **10 秒**。
- **濒死与拖尸**：被击倒后进入濒死，可被医疗机器人（**每夜 2 次电量、每次施救 5 秒**）或医疗包救起；尸体可拖拽藏匿，搜尸可得到死因与移动痕迹。
  **AI 同样会用拖拽**：没有医疗包的人类 AI 会把濒死者一路拖进医疗间交给机器人；异形 AI 会把尸体拖到
  远离门与任务点的舱室角落藏起来（医疗间 / 会议室的尸体会被拖去别的舱室）。
- **搜尸会取走物资**：尸体会保留生前没花掉的**子弹 / 医疗包 / 物资申请单**；搜一次既取证（伤口、时间、是否被拖动）
  也把能带走的物资收进背包，背包装不下就留在尸体上，下一个人还能来搜。**AI 人类与 AI 异形都会搜尸取物资**。
- **收尸**：`D` 扛起尸体（移动降到 2.5 格/秒，尸体跟在身后），再按一次放下；报告、搜尸、收尸、施救
  都可以从 `W`/`E` 的交互轮盘里选，不用记一堆散键。
- **出刀者会发红**：任何角色出刀命中后，自身会有 **3 秒红身**（角色贴图染红 + 红色轮廓光），
  目击者更容易认出刚动手的人；红身只是表现层，不改变任何判定。

## AI 与规则模型

本作没有接入外部大模型，所有 AI 都是 `js/game.js` 内的本地规则模型：

- **AI 认知链**：每个 AI 维护自己的 `mind`（事件记忆 / 嫌疑分 / 证据理由 / 警觉度）。
  只记录自己**看见、听见或搜查到**的事实：刀击、枪声、尖叫、管道、拉闸、故障、机器人停摆、
  自动门、灯光变化、拖尸、保安拘留、尸体伤口/是否被移动/是否已检查，以及时间线里见过的人。
  事实进入证据链后按权重累加嫌疑分，再驱动报告、追凶、开枪、指控与投票；AI 不读取任何 `alien` 身份答案。
- **规则不是阵营禁区**：搜尸取物资、开枪、补给、假装维修、做任务换弹这些规则双方都会按概率使用，
  区别在动机与频率——人类日常做任务/维修，异形通常不做任务，只有为了拿子弹继续杀人时才会做；
  异形会假装维修来制造不在场。AI 仍然有阵营目标差异，不是“同一种行为脚本”。
- **AI 推理链扩展**：会用目击时间线给不在场的人**反向洗清**（`alibi_clear`），会判断枪击是否处决
  （目击者自己确证过被害者是异形时，`saw_shot.justified` 不怀疑开枪者），零证据指控会损耗发言者可信度
  （`empty_accuse`），替已被确证的异形辩护也会引来“同伙”嫌疑（`defended_suspect`）。
- **外观一致**：异形与人类使用同一套角色贴图、名字标签和状态；空闲时都不显示武器，只有真实出刀 / 开枪
  动作才亮刀 / 枪；DEV / 旁观者的身份标签是唯一的全知例外，不影响正常对局看到的外观。
- **确证（不是嫌疑，是结论，而且会记一辈子）**：亲眼看见**异形专属行为**——钻管道 / 出刀 / 破坏设备 / 停摆机器人——
  或看见某人**身上带着刚出刀的 3 秒红光**，AI 会把这个人记进 `mind.known`：嫌疑分直接拉满，
  会议指控点名道姓（「我确定：XX 是异形，我亲眼看见他钻管道」），投票必投他，开枪与追击距离也放宽。
  **`known` 是长期记忆**：普通记忆与嫌疑分每夜清空，但确证不随夜晚消失——之后每一场会议都会继续指控并投这个人。
  **开枪、拖尸、拘留**这些人类也会做的事只增加嫌疑分，永远不会升级成确证。
- **AI 人类**：按任务点维修（与玩家同耗时，**做完立刻接下一个，不再休息**）、开局延迟 2–8 秒、
  回中央会议室圆桌领取物资申请单、到军械 / 医疗专用补给点换子弹 / 医疗包、用医疗包救起视线内的濒死者、
  **没有医疗包时把濒死者拖到巡逻中的医疗机器人身边让机器人救回来**（降到 2.5 格/秒、留 `bodyMoved` 痕迹、
  会被目击者记成 `saw_drag` 证据）、**全船断电时最多派 1 名人类去配电室合闸**（3 秒站桩，走同一个 `pullBreaker`）；
  **看到故障/拉闸会优先直接去修**：最近 2 名人类赶去故障，锁定后不再被脚步声/任务点打断，避免来回踱步；
  **故障被队友抢修完成后立刻松手改道**，不会把剩下的 10 秒站在已经修好的设备旁；
  **会主动翻尸/搜倒地伤员取物资**（缺子弹/医疗包/申请单时走到尸体旁搜），
  **见过一次后会记住 30 秒**，离开视野也会专门绕回去收；**有申请单优先备弹**，
  对目击凶手或高证据目标开枪（人类与异形都可能成为目标；黑暗里只有近身 2.8 格视野）；
  听到尖叫/枪声/刀声且警觉度足够高时，会先去现场查看。
  **修任务时若已确证的异形在视野内快速逼近、算下来修不完**，会立刻弃修、转身逃跑而不是站着挨刀。
  发现濒死者会先搜尸取得伤口/时间/拖拽痕迹，再决定是否报告；**每具尸体只报道一次**，
  同一夜可以连续开多场会，没有证据时会议投票弃权而不是随机投人。
- **AI 异形**：优先挑**独处目标**（旁边有人看着的对象会加一段风险距离），
  并**优先挑选正在站桩做任务/维修的人**（目标评分减 12 格，被围观惩罚仍会抵消）。
  贴脸时只统计**非队友**目击者：
  1 个非队友时 55% 直接冒险出刀；2 个以上非队友时**直接放弃这个目标**，转去找落单者——不再原地来回踱步；
  如果围观者全是已认出的队友，则照常出刀配合。其余行为：贴脸出刀、钻管道（20 秒冷却，
  **目标很远时会自己寻路到管道口再钻**，每夜最多两次）、指定拉闸手断电、每夜一次破坏舱室；离活人 5 格内优先处理人。
  贴身遇到机器人时**先用刀砍装甲**（消耗刀数，与玩家 Q 同一条 `knifeBot` 结算，保安两刀 / 医疗一刀），
  刀用完了才动用每夜一次的破坏技直接停摆。
  **杀完人有时会绕一圈再回来"发现"尸体并拉铃**（先离开 5–12 秒、找 6–24 格外的房间做不在场，再回现场报告），
  用会议拖人类的时间、顺便把自己包装成报案人；**偶尔也会直接原地报案**——不绕场做不在场，
  停顿 0.8–2 秒就拉铃，开会更快但更像凶手。
  代价是**尸体还热就有人来报**会被见过尸体的人记成可疑
  （`quick_report`，死亡 10 秒内报告才触发），告发得太快反而引火上身。
  异形会记住当场目击自己的活人并优先处理；也会在确认没有活人目击时自报尸体，
  用会议时间换取人类维修时间；**附近没有活人、自己又没被目击时会把尸体拖去藏**（每夜最多 2 次；
  目的地**永远排除医疗间/会议室/当前房间**，先排除有活人的房间，再在“远离医疗间”的前三名里随机，
  不再每局固定拖去仓库；拖尸途中遇到非队友目击会立刻松手）。
  人类目击者若看到尸体被**拖离医疗间**，会记下“反常拖尸”嫌疑（只加嫌疑、不写确证）。
  **出刀前预判保安机器人的 10.5 格 / 180° 扇形**，正被看着就宁可废刀不动手，等机器人转开再补刀。
  **规则也会用**：翻尸/搜倒地伤员拿子弹、医疗包、申请单，回圆桌领申请单、到军械补给点换子弹、
  有子弹时会远距离开枪；**假装做任务**——有人看着时去任务点站 4–8 秒，动画像在维修但不加任何进度，
  用来制造“我在做任务”的不在场证明；**真做任务只是少数策略**：每只异形整局最多 1 次，
  只在没刀没弹、缺申请单且人类进度低于 38 时小概率发生，不会替人类推完 45 分。
  假装维修仍只在故障旁有人看时发生，不修好、不加进度；手里有医疗包且认出队友倒下时会优先救队友。
  **管道机动**：目标超过 15 格且 20 秒冷却结束时，会先规划到能显著缩短距离的管道口再钻过去
  （每夜最多 2 次）；刀用完后也会继续用管道接近目标，不再原地游荡。
  **队友识别靠目击，不靠系统队友表**：异形看到某人钻管道、带红光、断电拉闸、破坏设备/停摆机器人，
  就把这人记成队友；此后不把他当刀下目标、不会投他，会议里会公开为他辩护；出刀时会避开队友正在追的目标。
  没被亲眼认出的同类仍然可能被攻击/指控/投票——异形之间不共享身份、目标/指控/投票不按阵营过滤。
- **异形主动构陷**：会议里会主动先发制人，声称看见某人“身上冒红光”；如果它已经认出队友，队友会帮腔
  “我也看见了”，共同把水搅浑（`frames[].ally`）。反咬/帮腔只走 `heard_frame` 传闻嫌疑，绝不写 `known`。
- **异形会议欺骗**：被确证后会先**反驳**，再可能**反咬**某人“钻管道 / 身上带红光”；
  假话只制造少量传闻嫌疑（`heard_frame`），**绝不写入任何 AI 的 `known`**，真目击者的指控与投票仍锁定真凶。
  说谎者的假口供若与被听众自己的 `saw_agent` 时间线对不上，会被当场拆穿并反过来背上嫌疑
  （`contradiction_lie`），所以构陷不是无风险。
- **会议语料**：开场、口供、质疑、作证、回应、指控、辩护、跟票、弃权均由真实证据和口供生成；
  直接目击会说出“亲眼看见”，确证会直接点破具体行为与舱室，时间线冲突会说“对不上”，
  尸体报告会带上伤口/是否移动/是否已检查。台词按席位、夜数、会议轮次与性格轮换，避免全场复读同一句。
- **会议模板**：发言框上方提供 8 个默认句式——`怀疑 / 投他 / 作证 / 看见钻管道 / 看见红光 / 看见出刀 / 我在… / 不是我`；
  先选对象（和舱室）再点模板，句子会直接以玩家身份发出，保证被 `parseSpeech()` 识别，不需要背关键词。
  **管道口供必须落在真正有管道口的 6 个舱室**（引擎室 / 监控室 / 军械库 / 仓库 / 食堂 / 医疗间）：
  模板选到无管道舱室时会自动省略地点；AI 构陷“钻管道”也会改到有管道的舱室，不再说出“在医疗间钻管道”这种不可能的口供。
  玩家硬要这么说时，AI 会把它当成物理上不可能的说法，反过来怀疑发言者（`impossible_claim`）。
- **玩家词库与直接证据**：自由发言会被拆成「人 / 舱室 / 指控 / 投票 / 支持 / 否认 / 自述位置 / 直接证据」；
  支持 `3号 / 三号 / 第3号` 等席位写法与常见舱室别名，能区分“我看见X在配电室”和“我在配电室”，
  也会处理“X不是异形 / 别投X”这类否定。玩家说“我看见X钻管道/出刀/带红光”会进入 `heard_claim` 传闻链：
  有确证的人公开站队，其他人只加少量嫌疑；如果案发舱室与听众的 `saw_agent` 时间线冲突，
  AI 会反过来怀疑玩家（`contradiction_claim`）。玩家提供的证据**不会**写成 `known`。
- **讨论时长**：开局公开讨论 60 秒会被真正填满——台词按 1.0~1.6 秒一条铺开，讲完后每 9 秒交替插入
  系统提示（剩余秒数）与 AI 主动追问，直到结束前 2 秒才收尾，不再“前 7 秒热闹、后面 50 秒死寂”。
- **机器人**：医疗机器人 **9 点**、保安机器人 **4 点**巡逻；医疗机器人 **6 格施救、每次 5 秒、每夜 2 次电量**；
  保安机器人 **10.5 格 / 180°** 半圆内**先追捕再押送**、拘留 **30 秒**、每夜最多 2 次。
  机器人可被刀/枪摧毁，保安会反制攻击者；**摧毁与拘押都不再公告**。
- **报告节奏（2026-10-30 改版）**：不再限制“AI 每晚只开一次会”，改成**每具尸体只报道一次**
  （`reported` 跨夜保留）。**异形会主动报告来拖时间**：按人类进度算收益、按旁边有几个人看着算暴露风险，
  再乘一个每夜固定的性格系数，超过阈值才去拉铃——人类快赢时最积极，被人盯着时宁可不报。
  **人类只在有实际线索时才报**（警觉度 / 高嫌疑 / 已确定凶手），**一旦确定凶手就一定报告**。
- **设计参考**：Among Us 的自我报告 / 假任务 / 会议证据链设计
  （[Guide:Impostor](https://among-us.fandom.com/wiki/Guide:Impostor)、
  [Guide:Report](https://among-us.fandom.com/wiki/Guide:Report)、
  Golechha & Garriga-Alonso, [Among Us: A Sandbox for Measuring and Detecting Agentic Deception](https://arxiv.org/abs/2504.04072)）。
- **已知边界**：普通事件记忆不跨夜；但**确证身份与目击到的队友关系会保留**。没有异形全局队友表/共享目标，
  也没有长文本语义理解；AI 异形仍按全图位置选目标（位置层面全知，但没有身份信息；会按目击风险优先挑独处的人），
  也不会主动维修故障（玩家异形可以）；AI 幽灵现在会做任务/故障，但严格受 2 分额度限制。
  玩家自由发言只做关键词/槽位匹配。这些是后续接入模型或扩展规则时的优先项。

## 蒙特卡洛基线（2026-10-31 最终复跑）

`npm run sim` 跑 **1000 局 AI 对 AI**（旁观者局，无玩家操作；固定 seed `20261030`，可复现）：

- **人类 431 胜（300 维修 45 分 / 131 清剿）/ 异形 568 胜 / 超时 1 = 43.1% / 56.8%**
  （95% Wilson 区间 40.1~46.2）。这是**保安/医疗机器人削弱 + 整船扩到 98×94 + 真实掩体重排**之后的读数：
  上一轮同口径是 54.9% / 44.9%；家具尚未重排时复跑是 42.2%，重排后 43.1%，两次差异在噪声内。
  **胜率翻转的主因是机器人削弱与走廊变长，不是“把大件改成掩体”。**
  **想调回五五开**：把 `NIGHT` 从 120 加到 ~130，或把 `WIN_PTS` 从 45 降 1~2 分；**不要动报告规则**。
- 平均 **6.23 夜**、14.76 次会议、11.19 次出刀、7.82 次破坏、2.19 次开枪、2.01 次驱逐；
  结束时人类存活 2.34/11、异形 1.23/4，平均维修进度 38.9/45（中位数 41）。
- **AI 规则使用率**：异形真做任务 0.41 次/局、假装做任务 1.01、假装维修 0.14、钻管道 **5.62 次/局**（规划 10.18）；
  搜尸 6.31 次/局，双方取到物资 4.05 次/局，复活 0.59 次/局。
- 解读：会议 14.8 次是**每具尸体都能报告一次 + 跑图变长**的伴随结果；控制刀数后会议多并不是简单的“人类更吃亏”。
  原始结果见 `tools/mc-results.json`，汇总见 `tools/mc-report.md`。方法/局限写在 `tools/monte-carlo.cjs`
  头部（不模拟玩家发言，夜会议按 30 秒扣夜）。
- 模拟还发现并修复了一个真实的寻路 bug：**A* 目标在地图外时 `prev[负数]` 为 undefined，重建路径会死循环**；
  `geo.astar` 现在会先做越界/不可走检查并安全返回 `null`。

| `R` | 报告尸体 |

## 项目结构

```text
index.html                 入口页面（唯一的 script 加载清单）
js/
  config/version.js        版本与元信息（返航录V3 单一真源）
  data/map.js              舰船地图静态数据（房间/走廊/家具/任务点/管道/墙体）
  ui/templates.js          游戏界面 CSS / HTML 模板
  ui/home.js               主页：由 SKMapData 生成整船 SVG + 手电遮罩 + 身份锚亮
  ui/replay.js             对局复盘：事件时间轴 + 0.5 秒位置帧播放 + 回放导出/载入
  engine/
    clock.js               相位时钟 / 个人技能槽 / 动作请求队列
    invariants.js          对局不变量断言（只读检查）
    geo.js                 几何 / 可行走网格 / A* 寻路 / 视线
  game.js                  对局编排：状态、AI、会议、渲染、输入
  main.js                  开始页绑定与版本号填充
assets/                    场景、角色、底图等素材（许可见各子目录 LICENSE）
audio/                     音效与来源记录（CREDITS.md）
tools/
  serve.cjs                零依赖静态服务器（npm start）
  test-v3.cjs              浏览器断言门禁（Playwright）
  blender-ship.py          2.5D 底图烘焙脚本（需 Blender；读取 js/data/map.js）
  gen-materials.py         家具/掩体表面材质生成（本地 SDXL 出图；--mode reuse 为无显卡兜底）
  sfx-audit.py             音效量化体检（峰值 / 短窗 RMS / 动态 / 起始静音；--check 校验游戏内引用）
  master-sfx.py            用 tools/_sfx 公共 CC0 素材分层混音 + 归一，产出 audio/sfx-*.ogg
  gen-hull.py              船体底板 hull-deck.png 程序化生成（与底图同尺寸同色温）
  map-check.cjs           离线地图体检（可行走网格 / 掩体审计 / 巡逻线 / 任务点可达）
```

分层约定：**数据（js/data）→ 引擎（js/engine）→ 编排（js/game.js）→ 入口（js/main.js）→ 主页（js/ui/home.js）→ 复盘（js/ui/replay.js）**。
所有脚本都是有顺序的经典脚本（IIFE + `window.SK*` 命名空间），不使用 ES Module 与构建步骤。
