# 太空杀 · 三阵营对抗（网页版）

依据《太空杀规则正式版 v2.0》与《太空杀系统显示方案》实现的**可玩前端原型**：
真实计时窗口、实时公开讨论、私聊双向确认与聊天、六分区记事本、上帝视角复盘、合成 BGM 与音效、
零依赖 WebSocket 联机（空席位 / 断线者由 AI 托管）。

## 预览版说明

> **本作为可玩预览版。** 后续将**全力优化 AI 判断逻辑与 AI 语言** —— 包括证据链推理、
> 指控与辩护的措辞、公开发言的博弈深度。当前 AI 行为可完整跑通对局，但语言与判断质量
> 仍在迭代中，请以「可玩原型」而非「完成品」预期体验。

配套站点（**附件**）→ https://space-kill.pages.dev

- 规则全文、剧情（人类 / 异形 / 外星人三线）
- 蒙特卡洛模拟成果：规则平衡性、策略矩阵、异形流派校验
- 可玩网页版 → https://space-kill-web.pages.dev

## 运行

```bash
cd space-kill-web
python -m http.server 8000        # 单机：浏览器打开 http://localhost:8000
node server/server.js             # 联机：同地址即可（自带静态服务与 WebSocket，端口 8766）
```

单机也可以直接双击 `index.html`（file:// 可运行）。联机时在开始页创建/加入房间，房主开局；
`npm start` / `npm run sim` 为快捷脚本。

## 玩法

1. 选阵营偏好与随机种子 → 开始对局，系统分配身份。
2. 夜间按步骤推进：需要你操作时会自动停下并弹出决策面板，其余步骤点「继续」。
3. 右侧四个页签：公告流（①~⑫ 批次）、私人反馈、我的面板（资源与状态）、记事本（已确认身份 + 手写备注）。
4. 出局后自动进入旁观，对局由系统接管跑完，结束后解锁全知视角。

## 结合层：语言 ⇄ 推理 ⇄ 行为（引擎核心）

公开发言——无论出自玩家还是 AI——**只走一个入口** `Bridge.say()`，形成闭环：

```
玩家/AI 说话 → lang 产出 Claim IR → infer 按 kind 路由到推理链 → 写入证据台账
             → 影响各 AI 的威胁度 → 影响其投票 / 夜间决策 / 下一轮发言
                                  ↑____________________________│
```

| 新增文件 | 职责 |
|---|---|
| `js/lang/ir.js` | `Claim IR`：语言层与推理层唯一的交换格式（`fromSig` 把旧的 Sig 升级为带视角与档位字段的断言） |
| `js/lang/renderer.js` | 生成侧：`Claim IR → 中文句子`，与 `nlp.js` 互为逆运算，由 round-trip 测试锁死 |
| `js/infer/speakable.js` | 推理 → 语言：AI「能安全说出什么」的候选发生器（只有自己确实持有的信息才成为候选） |
| `js/infer/pipeline.js` | 结合层：统一发言入口、Claim 路由、证据台账、质询-应答闭环 |

要点：
- **AI 与玩家完全对等**：改造前 AI 发言只有「指控 / 质询」两个意图生效，玩家有七类；现在同一条管道、同一套权重。
- **不改任何权重数值**：路由只调用既有 AI 钩子；`defend / rally / abstain / bind / 各类私有体验` 在数值方案落地前只进证据台账 `g.evidence`，不改估值。
- **AI 不蠢**：`speakable` 只从「发言者确实持有」的私有信息里出候选，没有持有就不开口。
- 回退开关：`SK_LEGACY_AI_ROUTE=1`（环境变量）可让 AI 侧只走改造前的 accuse/ask 两路，用于对拍回归。

## 主要功能

- **计时窗口**：每个决策步骤按 B 类参数开窗倒计时，全员提交即跳秒（AI 有模拟思考时间），
  超时视为放弃（投票=弃票、抑制=不使用）；可勾选「快速模式」跳过等待。
- **私聊**：拆成 0a 发起邀请 → 0b 处理邀请（双向确认才配对）→ 0c 正文；对方回复即时显示在步骤区，
  并进入「私人反馈」页签；AI 邀请目标随机分布，不再全场扎堆。
- **实时公开讨论**：白天 / 会议讨论为流式窗口（75s / 60s），AI 陆续表态、玩家随时插话，
  发言立即上屏并写入记事本「发言」区；可点名**公开指控**与**公开质询**——计入威胁度，真实影响 AI 投票。
  发言经 NLP 意图模型解析（黑话语料对齐：金水/查杀/悍跳/踩/归票/压手/划水/sus 等，
  支持中文数字+职业绑定如「十二号位」「医生12号」），每条发言下方以小字「原意」展示解析结果。
- **记事本六分区**：公告流 / 发言 / 私人 / 状态·阵营 / 出局 / 备注。
- **复盘**：结束后一键「上帝视角复盘」，按夜回放全部事件（含每人当夜真实行动、攻击结果、
  私人反馈、票型——金色条目为隐藏信息），并公示全部身份。
- **音乐**：WebAudio 实时合成的太空氛围 BGM（pad + 五声琶音 + 星尘底噪），
  以及提交 / 公告 / 死亡 / 胜负音效，右上角 ♪ 可静音，无任何外部音频资源。
- **联机**：`node server/server.js`（零依赖，手写 WebSocket 帧协议）。权威状态在服务器运行，
  按席位广播裁剪视图（医生才看得见感染名单、异形才看得见队友刀数……）；
  断线者由 AI 接管且不产生任何标识（对应正文 1.2 挂机条款）。当前为实验性功能，仅建议本地局域网体验。

## 原型期的简化（非规则改动，仅为可玩性）

- **讨论**：无实时语音，AI 与玩家发言均为文本；转写回显、静默检测等 B 类运营参数未实现。
- **挂机/举报/护卫队**：属运营治理层，未纳入。
- **联机**未做压力与断线重连的完整打磨。

## AI 与平衡

AI 只使用它按规则应当掌握的信息：异形仅知队友；神探只用已查验池；外星人只用自身查验结果；
其余判断全部来自公开公告、公开发言中的指控（威胁度）与船员公开的查验结论——**不按 role 直接锁定人类关键角色**。

`tools/sim.cjs` 是无头模拟器（纯 AI 对局 / 带真人席位两种模式），`tools/uismoke.cjs` 为 UI 冒烟，
`tools/verify-heat.js` 验证指控热度确实影响投票，`tools/test-fix-v26.cjs` 是 **71 条**缺陷回归断言：

```bash
npm run test:all                # 回归断言 + round-trip + UI 冒烟 + 60 局模拟（推荐）
node tools/sim.cjs 300          # 纯 AI（npm run sim）
node tools/sim.cjs 120 human    # 模拟真人随机决策，覆盖表单通路（npm run sim:human）
node tools/mc.cjs 500 1         # 蒙特卡洛 500 局（npm run mc）
node tools/test-fix-v26.cjs     # v26 缺陷回归：硬源锁定 / 透视 / 宣称目标侧证据 / 承诺兑现 / K2 判据…
node tools/verify-heat.js       # 共识热度与出局的相关性（只观测，不作验收靶）
node tools/test-lang.cjs        # 语言库 round-trip：render → parse → IR 深比较（含 payload 关键字段）
```

> round-trip 为**深比较**：只比 kind + targets 会漏掉 `lock.faction`（目标侧证据与硬源锁定的
> 唯一载体）与 `accuse.tier`（措辞强度）。

`test-lang.cjs` 是「语言库 ⇄ 推理链」联动的地基：AI 说得出的每句话都必须能被自家解析器读回同一个意图，
否则推理链接收到的就是噪声。它已反向校出 renderer 的措辞缺陷与 `nlp.js` 里中文编号（`五号`）解析失效的问题。
